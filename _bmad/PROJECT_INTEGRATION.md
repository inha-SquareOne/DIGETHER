# DIGETHER BMAD 적용 경계

Unreal Engine **5.8.2**, 한국어, 프로젝트 파일 관리 **GitHub**를 따른다. 플랫폼 선택은 `unreal`이다. 사용자 이름은 신원을 추측하지 않는 `Project contributor` 기본값이다.

기획 운영 원본은 **Notion**이며 이관 전 기준은 `docs/GAME_DESIGN.md`다. BMAD의 “GDD canonical source”는 이 프로젝트에서 승인된 Notion 기획과 동기화된 작업용 사본을 뜻한다. 새 출력은 `_bmad-output/planning-drafts/`의 미승인 초안으로 분류하며 기존 기획을 자동 대체하지 않는다. 기술·실행 산출물은 `_bmad-output/implementation-artifacts/`로 분리한다. 기획 동기화·외부 게시·커밋·푸시는 현재 사용자 요청에 따른다.

사용 전 `AGENTS.md`, `docs/project/PROJECT_PROFILE.md`, `docs/project/DOCUMENTATION.md`, `docs/ai/EXECUTION_POLICY.md`를 확인한다. 스킬의 에이전트·자동화·테스트 안내는 사용 가능한 런타임과 승인 범위에서만 적용한다. 설치 자체는 실행, 위임, 업로드 또는 외부 전송 승인이 아니다. 현재 엔진 프로젝트·환경의 부재는 성공으로 보고하지 않는다. 네트워크와 게임 규칙을 추정해 확정하지 않는다.

관리 원본이자 Codex 발견 경로는 `.agents/skills/`, Claude Code 동기화 사본은 `.claude/skills/`다. 두 경로는 지원 파일과 상대 링크를 포함해 동일하게 유지한다. 공용 런타임·카탈로그는 `_bmad/`다. `uv`와 Python 3.11 이상을 사용한다. 사용자별 설정은 복사하지 않았다.

출처·라이선스·파일 해시는 `provenance/bmad-install/`에 보존한다. 이 설치는 로컬 고정 설치본의 재사용이며 upstream 전체와의 동일성을 주장하지 않는다.

## 가져온 절차의 적용 방식

판단과 실행 권한의 단일 기준은 [AI 실행 정책](../docs/ai/EXECUTION_POLICY.md)이다. 아래는 BMAD 용어를 이 프로젝트에 적용하는 방법이며, 팀·개인 override나 `on_complete`도 실행 권한을 새로 부여하지 않는다.

- **범위와 메뉴:** 사용자 요청이 특정 수정이면 관련 단계만 적용한다. 전체 인터뷰·모든 기획 산출물·메뉴 선택을 완료 조건으로 추가하지 않는다. `HALT`, `Approve`, `required`는 실제 미결 결정이나 권한이 필요할 때 적용하며 이미 받은 승인과 확정된 답은 재사용한다. 명시적으로 대화형 워크숍을 요청한 경우에는 그 상호작용을 유지한다.
- **위임과 모델:** `spawn`, 병렬 리뷰, 원문 추출 위임은 현재 사용자·런타임의 위임 권한과 모델 규칙 안에서만 적용한다. 위임이 없으면 동일 검토를 순차로 수행하고 독립 리뷰와 구분한다. 별도로 요구된 교차 검증은 생략하거나 자체 검증으로 대체하지 않는다.
- **변경과 복구:** HEAD만으로 시작 상태를 표현하지 않는다. 기존 미커밋 변경을 함께 파악한다. `revert`는 이번 작업이 만든 해당 변경만 대상으로 하며 전체 reset·clean을 뜻하지 않는다. 자동 커밋 지시는 적용하지 않고 커밋·푸시·게시 여부는 현재 사용자 요청을 따른다.
- **검증:** 테스트 범위는 [검증 수준](../docs/ai/VERIFICATION.md)과 [TDD 적용 범위](../docs/ai/TDD.md)를 따른다. `all tests`, 매 커밋 전체 회귀, 반복 완료 검사는 범위에 맞는 필수 검사로 해석한다. 실패와 새로운 변경이 없으면 같은 검사를 반복하지 않는다. 미실행 검사를 통과로 표시하지 않는다.
- **기획 권위:** story의 수용 조건은 승인된 Notion 기획·개정과 연결된 실행 계약이다. 로컬 GDD·story·memlog가 사용자 최신 결정이나 Notion 운영 원본을 덮어쓰지 않는다. 기획 충돌은 출처를 확인하며 엔진·플랫폼별 예시는 프로젝트 결정으로 승격하지 않는다.
- **사용 안내:** 새 기능은 엔진 공식 지원 조사와 사용 가이드를 먼저 제공하고, 문제 해결은 원인과 재발 검증으로 마무리한다. 저장 문서는 문서 기준 상대 링크, 대화에서는 현재 호스트의 클릭 가능한 링크 형식을 사용한다.
