# DIGETHER

**길은 함께 파고, 돈은 각자 챙기는 1~4인 협동 굴착 호러.** Team Square One의 Unreal Engine **5.8.2** 프로젝트입니다.

기획은 **Notion**, 소스 코드·Unreal 에셋·기술 문서는 **GitHub**에서 관리합니다. Issue/PR을 통한 변경 검토 절차는 초기 운영안입니다.

## 담당별 시작하기

| 담당 | 먼저 읽을 문서 |
|---|---|
| 기획반 | [기획 가이드](docs/guides/planning/README.md) — Notion 작성·변경 요청·결과 확인 |
| 아트반 | [아트 가이드](docs/guides/art/README.md) — 제작·파일 전달·에셋 편집 협업 |
| 개발반 | [개발 가이드](docs/guides/development/README.md) — 환경 준비·기능 조사·구현·검증 |
| GitHub가 처음인 팀원 | [GitHub 첫 사용](docs/guides/GITHUB_BEGINNER.md) — 웹과 Desktop으로 협업하기 |
