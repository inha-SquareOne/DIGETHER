# DIGETHER 게임 기획

기준일: 2026-10-28 · 상태: **제공된 작업 목록을 반영한 Notion 이관 전 초안**. 자료 내 확정 규칙과 시험 기준·미결을 구분한다. Notion 원문 URL·승인 개정은 아직 확인되지 않았으며 이 초안은 구현 완료나 팀 최종 승인 증거가 아니다. 세부 셀 출처와 충돌은 로컬 작업 기록에 둔다.

## 경험과 게임 루프

1~4인 온라인 협동 굴착 호러다. 거점에서 장비를 준비하고 갱도를 선택해 출발한다. 굴착과 던전 탐사로 화물을 찾고 위험을 피해 엘리베이터 또는 긴급 탈출로 귀환한다. 탐사가 끝나면 회수품을 정산하고 거점에서 장비 구매·목표 납부를 진행한다. 혼자서도 처음부터 끝까지 플레이할 수 있어야 한다. Cartoon Rendering + Low Poly는 기존 기획 방향이다. 출시 방향은 Steam 판매(2026-10-29 사용자 결정)이며 성능 목표·지원 OS·다른 플랫폼 출시는 미정이다.

2026-10-28 사용자 추가 지시로 굴착 경험은 **Digging a Hole처럼 조준한 흙이 실제로 깎이고, 구멍을 옆으로 넓히거나 아래로 파 내려가는 방식**을 따른다. 갱도의 지정 굴착 대상은 허용된 3D 흙 볼륨을 뜻하며, 큐브의 크기만 줄이는 동작으로 완료하지 않는다. 원본 T02~T03의 벽·바닥·천장 방향별 허용 영역, 동시 굴착 시 실제 제거량만 반영, 비허용 구조물 보존 조건은 유지한다. 던전은 지정된 파괴 가능 벽만 별도로 변경한다. 구현 계약과 시험 범위는 [굴착 구현 설계](design/EXCAVATION_IMPLEMENTATION.md)를 따른다.

추가 이미지의 어두운 Low Poly 광산, 따뜻한 작업등, 목재 보강, 철제 승강기, 1인칭 도구와 폐교 분위기를 프로토타입 표현 목표로 반영한다. 이는 최종 아트 승인이나 새 게임 규칙의 근거가 아니다. 이미지의 수분 등 아이콘을 생존 자원으로 추가하지 않으며 보이스 제외 범위도 유지한다.

### 일차·탈출·경제

탐사 한 번이 끝나면 일차가 즉시 한 번 증가한다. 4일차 출발 게이지가 완료되면 납부 마감이고 미달이어도 출발할 수 있다. 미달 기록은 4일차 탐사 후 거점에 돌아왔을 때 게임 오버가 된다. 목표를 먼저 달성하면 즉시 새 목표·1일차가 되고 진행 중 출발 게이지는 취소된다. 시작 목표, 증가량과 1~3일차 인정 비율은 작성 중이다.

엘리베이터는 처음 하강한 뒤 최대 두 번 상승하고 1차 회수 뒤 자동 하강한다(2회 시험 프로필). 레버를 완료한 순간 사람과 화물 목록을 고정하고 실제 운행 성공을 별도로 확정한다. 무게 초과 입력은 출발하지 않으며 진행 중 초과하면 게이지를 초기화한다. 시간 종료 순간 대기 중 엘리베이터가 초과 중량이면 사람·물건을 사출하고 해당 편의 회수를 취소한다. 상승 중 시간 종료는 진행 중인 편을 마친다. 전멸이면 이미 올린 물품도 사라진다.

일반 화물 T를 출발 인원 N으로 나눈 몫은 내림하며 생존자에게만 지급한다. 죽은 사람의 몫과 나머지는 분배하지 않는다. 죽은 사람의 장비와 히든 물건은 떨어지며 장비에는 귀속 소유권이 없다. 수익·손실과 시체 복구를 분리하고 동일 탐사의 재처리는 중복 지급하지 않는다.

## 콘텐츠와 선택 범위

폐교와 피라미드 던전은 기존 기획 방향이다. 아이템·경제 데이터와 최초 몬스터 1~2종은 작성·선정 중이다. 사다리·무전기·함정 등의 선택 기능은 개별 채택 전 범위에 넣지 않는다. 산소, 차량, 날씨, 전투 전용 무기, 엘리베이터 성능 업그레이드는 현재 채택 범위가 아니다. 장비의 공격과 팀킬은 포함한다. [결정 목록](planning/DECISIONS.md)과 [검증 계획](verification/VERIFICATION_PLAN.md)을 따른다.

기존 DG-001~019는 이전 기획 추적 ID이며 새 S ID로 자동 치환하거나 승인을 추정하지 않는다. 관련 Notion 요구의 실제 URL·개정과 기획 승인 상태를 확인한 뒤 연결한다.
