## 경험과 게임 루프

1~4인 온라인 협동 굴착 호러다. 거점에서 장비를 준비하고 갱도를 선택해 출발한다. 굴착과 던전 탐사로 화물을 찾고 위험을 피해 엘리베이터 또는 긴급 탈출로 귀환한다. 탐사가 끝나면 회수품을 정산하고 거점에서 장비 구매·목표 납부를 진행한다. 혼자서도 처음부터 끝까지 플레이할 수 있어야 한다. Cartoon Rendering + Low Poly는 기존 기획 방향이다. 출시 방향은 Steam 판매(2026-10-29 사용자 결정)이며 성능 목표·지원 OS·다른 플랫폼 출시는 미정이다.

2026-10-28 사용자 추가 지시로 굴착 경험은 **Digging a Hole처럼 조준한 흙이 실제로 깎이고, 구멍을 옆으로 넓히거나 아래로 파 내려가는 방식**을 따른다. 갱도의 지정 굴착 대상은 허용된 3D 흙 볼륨을 뜻하며, 큐브의 크기만 줄이는 동작으로 완료하지 않는다. 원본 T02~T03의 벽·바닥·천장 방향별 허용 영역, 동시 굴착 시 실제 제거량만 반영, 비허용 구조물 보존 조건은 유지한다. 갱도의 굴착 규칙은 던전에 적용하지 않는다. 던전 지정 벽 파괴는 시스템 작업리스트 1.1.0에서 검토 단계(D41)로 바뀌었고 레벨 디자이너가 채택을 결정한다. 결정 전에는 구현 범위가 아니며, 작업리스트 안의 P0 벽 파괴 서술과의 차이는 PQ-18이다. 구현 계약과 시험 범위는 [굴착 구현 설계](design/EXCAVATION_IMPLEMENTATION.md)를 따른다.

추가 이미지의 어두운 Low Poly 광산, 따뜻한 작업등, 목재 보강, 철제 승강기, 1인칭 도구와 폐교 분위기를 프로토타입 표현 목표로 반영한다. 이는 최종 아트 승인이나 새 게임 규칙의 근거가 아니다. 이미지의 수분 등 아이콘을 생존 자원으로 추가하지 않으며 보이스 제외 범위도 유지한다.

## 용어

시스템 작업리스트 1.1.0 '개요·공통규칙' 시트의 용어다. 문서와 코드 주석은 이 뜻으로 쓴다. 기획 공유 사양 2026-11-05의 '로비'는 이 문서의 '거점'과 같다. 메인 메뉴에서 방을 만들거나 참가한 뒤 게임 시작 전 인원을 모으는 화면은 '대기실'로 구분해 부르며 거점과 다른 단계다(코드 폴더 이름은 `Game/Frontend/Lobby`).

| 용어 | 뜻 |
|---|---|
| 게임 | 새 게임 시작부터 게임 오버(납부 실패)까지의 전체 플레이. 결과 크레딧 통계 범위이며 S33의 '해당 런'도 이 뜻이다 |
| 기간 | 납부 목표 하나를 채우는 1~4일차 묶음. 4일차 출발 레버를 끝까지 당긴 순간 그 기간의 납부가 마감된다(마감 시점 표현 차이는 PQ-22) |
| 일차 | 모든 플레이어가 함께 쓰는 날짜. 탐사 종료가 확정되는 즉시 1 오른다. **전체 일차**(게임 시작부터)와 **기간 일차**(현재 할당량 기준 1~4일차)를 함께 기록하며, 납부 마감·실패 판정은 기간 일차 기준이다. 예: 전체 4일차에 첫 할당량을 채우면 이어지는 탐사는 전체 4일차 / 두 번째 기간 1일차이고, 마치면 전체 5일차가 된다. 게임 오버 흐름에서 말하는 '5일차'는 할당량 미달로 마감된 기간의 4일차 탐사가 끝나 기간 일차가 5로 넘어간 마감 초과 상태이며, 다섯 번째 탐사를 뜻하지 않는다 |
| 런 / 탐사 | 거점 출발부터 탐사 종료까지 한 번. 탐사 한 번이 게임 속 하루다 |
| 활동 인원 | 지금 위험에 노출된 사람(탐사 중·매몰). 탈출했거나 죽은 사람은 빠진다 |
| 탈출 완료 | 엘리베이터나 긴급 탈출로 생존 탈출이 확정된 상태. 관전자가 되며 그 탐사에서 되돌리거나 다시 내려갈 수 없고, 먼저 거점으로 돌아갈 수 없다 |
| 회수 건 | 엘리베이터 한 번 상승에 실린 화물과 사람의 묶음. 상승 레버 게이지를 채운 뒤 문이 완전히 닫힌 순간 목록을 고정한다. 사출된 편은 빼고, 긴급 탈출은 회수 건을 만들지 않는다 |
| 일반 회수품 | 정산 때 돈으로 바뀌는 아이템. 총액을 출발 인원으로 나눠 생존자만 받고, 정산 뒤 사라진다 |
| 히든 물품 | 히든 슬롯에 숨겨 주운 아이템. 팀 분배에서 빠지고 숨긴 사람이 살아 돌아오면 그 사람 수익이 된다 |
| 장비 | 곡괭이·삽·헤드랜턴·설치형 랜턴처럼 쓰는 아이템. 돈으로 바꾸지 않고 가지고 돌아오면 계속 쓴다 |
| 헤드랜턴 | 머리에 쓰는 조명. 전용 칸에 들어가 일반 슬롯을 줄이지 않는다 |
| 랜턴 | 바닥 등에 설치하는 램프. 헤드랜턴과 다른 장비이며 들고 다닐 때 일반 슬롯 1칸을 쓴다 |
| 호스트 | 방을 만든 플레이어의 컴퓨터. 획득·사망·탈출·정산 결과를 최종 결정한다. 나머지는 클라이언트이며 요청만 한다 |
| 제한 시간 | 탐사 한 번의 시간. 최초 하강을 마치고 갱도에 도착한 순간부터 흐른다. 숫자로 보여 주지 않고 여진 빈도로 짐작하게 한다. 상승할 때마다 `ELV_RUN_TIME_PENALTY`만큼 줄어든다(처음 하강 제외). '붕괴 시간'이라고 부르지 않는다 |
| 굴착 | 갱도에서는 굴착 가능 오브젝트(특정 흙 등)만 벽·바닥·천장 어디서든 판다. 던전 지정 벽 파괴는 검토 중(D41)이며 갱도 규칙을 던전에 적용하지 않는다 |
| 보강 | 플레이어·몬스터가 판 통로의 천장에 목재를 대 무너지지 않게 버티는 것. 여진으로 손상되어 영구적이지 않다 |
| 여진 | 탐사 중 주기적인 진동. 보강이 없거나 손상된 통로를 무너뜨리며 제한 시간이 줄수록 잦아진다 |
| 매몰 | 무너진 잔해에 깔린 상태. 1·2단계는 혼자 빠져나오고 3단계는 동료가 구해야 한다 |
| 정산 | 탐사가 완전히 끝난 뒤 유효 회수 화물을 돈으로 바꿔 나누고 히든 수익·시체 복구금과 함께 한 번에 지급하는 것 |
| 납부 | 거점 정산머신에 개인 돈을 넣어 팀 목표액을 채우는 것. 4일차 출발 전에 끝내야 한다 |
| 사출 | 제한 시간이 끝나는 순간 엘리베이터 무게가 한도를 넘으면 바닥을 열어 안의 사람과 물건을 모두 내보내는 것. 이때만 일어나며 그 편은 탈출·회수로 치지 않는다 |
| 실종 | 종료 컷신 때 갱도·던전에 남아 사망 처리된 상태. 시스템은 사망과 같고 런 결과 화면 표시만 '실종'이다 |
| 통로 붕괴 / 광산 붕괴 | 통로 붕괴는 여진으로 판 통로 일부가 무너지는 것(S09, 잔해·매몰 발생, 다시 파면 지나감). 광산 붕괴는 제한 시간 종료로 광산 전체가 무너지는 것이며 탐사 종료와 같다(S18). 수식어 없는 '붕괴'는 통로 붕괴다 |

## 기능 요구와 경계

기능 번호 S01~S35는 시스템 작업리스트 1.1.0 기준이다. 아래는 범위 요약이며 [전체 시스템 설계](SYSTEM_DESIGN.md)의 흐름·계약과 함께 읽는다. 검증 항목은 목표이지 수행 결과가 아니다.

| 기능 | 요구 |

| S01~S05 | 호스트형 방과 1~4인, 출발·일차, 이동·체력·시점, 조준 상호작용, 절차 생성 갱도와 던전 배치·진입. 호스트는 방을 만들 때 새 게임 또는 저장 슬롯과 공개 범위(초대 전용 / 친구 공개 / 공개)를 고른다. 초대는 Steam 초대와 방 코드를 모두 쓴다. 신규 참가는 정상 거점 준비 상태에서만 받고, 출발 레버 게이지 완료 순간부터 출발 전환·로딩·탐사·정산·실패 사건·크레딧 동안 받지 않는다. 판정은 요청을 수락한 시점 기준이며, 수락은 게이지 전·확정은 그 뒤인 사람은 빈자리가 있으면 관전으로 합류하고 그날 출발 인원·수익에서 빠진다(MVP에서 관전 접속이 어려우면 임시로 거절·사유 안내. 수락은 호스트 처리 순간이며 Steam 초대 클릭 순간은 아님; 11-06 답변 20). 거점에서 나가거나 끊기면 캐릭터를 제거하고 자리를 반환하며 소지 장비는 그 자리에 남긴다. 출발 뒤 나가거나 끊기면 캐릭터·자리를 유지하고 재접속 시 같은 캐릭터의 최신 상태로 돌아온다. 거점에서 떠났던 사람이 탐사 중 돌아오면 관전하며 기다린다. 재접속으로 시작 장비·돈을 다시 주지 않는다. 문 닫힘 후 로딩 중 끊긴 사람은 개인 로딩 실패와 같이 출발 인원·캐릭터·자리를 유지하고 엘리베이터 안에서 시작한다. 재접속하면 그 캐릭터로 돌아오며, 생존 여부는 위치로 판정한다. 함께 상승하면 생존 귀환, 탐사 종료 때 갱도·던전에 남으면 실종·사망 손실을 적용한다(11-06 답변 16). 크레딧 중 끊긴 사람이 새 게임 거점으로 돌아오면 정원·버전·상태를 확인해 신규 참가로 처리하고 새 게임 시작 장비를 한 번만 준다. 이전 게임 기록은 결과 보관에만 남긴다(답변 17). 호스트가 나가면 방이 끝난다(호스트 이전 없음). 탐사 중 호스트 종료는 해당 탐사를 저장하지 않고 마지막 정상 저장에서 재개하며 별도 악용 대책은 두지 않는다(11-06 답변 18). 같은 계정 재접속은 사용자 결정(2026-11-05)으로 **이전 접속을 끊고 새 접속을 받는다**(작업리스트 S01의 '거절만'은 기획이 다음 버전에서 고칠 항목). 참가 실패 문구는 6종(계정 확인 실패·같은 계정 접속 중·탐사 중 + 정원 초과·버전 불일치·방 종료)이다. 구현(실행 검증 일부): 문 닫힘 중 참가 잠금. 구현(자동 테스트 통과, M2 미검증): 같은 계정 교체(`PreLoginAsync`에서 이전 연결 종료 후 수락, 교체 대기 5초 임시), 거점 이탈 시 캐릭터 제거·자리 반환(장비 남기기는 인벤토리 미구현), 로비 이탈자의 탐사 중 관전 복귀, 게이지 완료 뒤 확정자의 관전 합류, 참가 실패 6종(사유 키 전달), 게임 오버 중 신규 참가 잠금. 방을 만들 때 새 게임/이어하기 선택은 코드만 있고 WBP 위젯 추가가 필요하다. |

### 일차·탈출·경제

탐사 한 번이 끝나면 전체 일차와 기간 일차가 즉시 한 번 증가한다(결과 화면 종료나 다음 출발까지 미루지 않음). 4일차 출발 게이지가 완료되면 납부 마감이고 미달이어도 출발할 수 있다. 미달 기록은 4일차 탐사가 끝나 5일차가 되고 검은 개인 정산 화면을 거쳐 거점에 돌아왔을 때 게임 오버가 된다. 목표를 먼저 달성하면 즉시 새 기간·새 목표·1일차가 되고 진행 중 출발 게이지·경고는 취소된다. 4일차 게이지 완료와 마지막 납부가 같은 처리 시점이면 납부를 먼저 판정하고, 달성하면 완료된 레버로 새 사이클 1일차 탐사를 출발한다(정상 종료 시 2일차). 공통 출발 로딩 오류가 나도 이미 기록한 4일차 마감은 유지한다.

납부 인정 비율은 4일차 100% 확정, 1~3일차 30%·50%·70%는 사용자 결정(2026-11-05) 임시값이다(구현(실행 검증 일부)). 목표 반영액은 소수점 버림(예: 1일차 100원 납부 → 잔고 100 감소, 목표 30 반영). 첫 목표 100원·달성마다 +100원은 임시값이다. 정식 목표·증가량은 경제 담당이 정하며, 작업리스트 '조정 변수' 시트가 이 행을 '확정'으로 적은 것과 D22 '작업 중'의 차이는 PQ-19다. 새 게임은 개인 잔고 0원으로 시작한다. 시험 지원금 500은 개발 빌드 전용이며 출시 빌드에서는 주지 않는다(사용자 결정 2026-11-05, 구현). 4일차 마감을 게이지 완료 시점에 기록하는 처리와 전체 일차·기간 일차 분리는 구현(자동 테스트 통과)이다.

### 출발과 경고

| 1~3일차 | 주황색 형광등·비프음 | 팀원에게 “승강기가 곧 출발합니다” |
| 할당량 미달 4일차 | 빨간 경고등·사이렌 | 레버 조작자에게 “현재 할당량 마감일입니다!” |

게이지 완료 순간 구매·납부·신규 참가 접수를 닫고 열린 상점·외형·납부 창과 기본 조작 안내를 지우며 수동 출발 취소를 받지 않는다. 그 뒤 엘리베이터 문이 자동으로 닫히고(임시 3초, `LOBBY_DOOR_CLOSE_TIME`) 닫히는 동안 걸어서 탈 수 있다. 문이 완전히 닫힌 순간 거점에 있으면서 엘리베이터 밖에 있는 참가자 전원을 사슬 소집으로 엘리베이터 안에 옮긴다(순간이동 1회, 끌려가는 동안 충돌 판정 없음, MVP는 암전 후 순간이동). 엘리베이터 안에 놓인 공용 장비·물품도 함께 내려간다. 출발 인원 N은 이 순간 확정한 인원(직접 탑승 + 사슬 소집, 자리 비운 사람 포함, 관전 합류자 제외)이며 정산과 1인 판정의 기준이다. 문 닫힘 단계와 문 닫힘 중 참가 잠금은 구현(실행 검증 일부)이다. 레버 한 번 완료로 자동 닫힘, 게이지 완료 뒤 취소 불가·거래와 창 닫기, 닫히는 중 탑승, 사슬 소집, 1~3일차 출발 경고는 구현(자동 테스트 통과, M2·연출 미검증)이다. 사슬 소집은 MVP 순간이동이고 클라이언트 암전은 BP 이벤트 `OnChainSummoned` 연결이 필요하다. 경고 종류는 `WarningKind`로 복제하며 형광등·소리 연출 BP가 필요하다. 출발 방식은 플레이테스트 결과에 따라 바뀔 수 있다.

### 엘리베이터 운행

엘리베이터는 최초 하강 → 1차 상승 → 재하강 → 2차(최종) 상승 순서로만 움직이고, 1차 회수 뒤 호출 없이 자동 하강한다. 상승 레버 게이지(U, 거점 T와 별개)를 다 채우면 문이 자동으로 닫히고(임시 3초, `ELV_DOOR_CLOSE_TIME`) **문이 완전히 닫힌 순간** 사람과 화물 목록을 고정한다(구현(실행 검증 일부)). 닫히는 동안에도 탈 수 있으며, 이전에 검토한 문턱 밀어내기는 폐기했다(사용자 결정 2026-11-05). 갱도에서는 사슬 소집이 없고 문 닫힘 완료 때 안에 있는 사람만 상승한다. 제한 시간은 갱도 도착부터 흐른다. 아래 문 닫힘 중 무게 초과·시간 종료 처리와 문 닫힘 우선 판정은 구현(자동 테스트 통과, M2 미검증)이다.

| 상황 | 처리 |
|---|---|
| 제한 시간 전 무게 초과로 레버 | 경고 메시지·덜컹거림만. 게이지·목록·상승 횟수 변화 없음 |
| 게이지 중 무게 초과 | 게이지가 끊기고 0. 다시 당겨야 함 |
| 문이 닫히는 중 무게 초과 | 문이 다시 열리고 게이지 0. 상승 횟수에 넣지 않음 |
| 문이 닫히는 중 시간 종료 | 갱도 대기로 처리(정상 중량이면 자동 귀환, 초과면 사출). 문 닫힘 완료와 시간 종료가 같은 처리 시점이면 문 닫힘 완료를 먼저 판정 |
| 시간 종료 순간 대기·초과 중량 | 안의 모든 것을 사출하고 빈 엘리베이터만 상승. 사출된 사람은 사망(실종 표시), 그 편 회수 취소 |
| 상승 중 시간 종료 | 진행 중인 편을 마친다. 시간 초과만으로 실종 처리하지 않지만 다른 피해 사망은 반영 |
| 상승 중 탑승자 사망 | 사망으로 기록. 그 시체가 지상에 도착하면 시체 회수로 판정 |
| 활동 인원 0명 | 문 닫힘 완료로 이미 상승이 확정된 편만 지상까지 운행. 대기·문 닫힘 중인 편의 화물·시체는 회수하지 않음 |
| 2차 상승 완료 | 제한 시간이 남아도 탐사 종료, 잔류자 전원 사망 |
| 문 닫힘 완료 뒤 취소 | 취소하지 않음. 거점 출발의 공통 로딩 실패만 예외(11-06 답변 06) |
| 화물 전용·빈 상승편 | 상승 1회로 세고 남은 시간을 줄임. 과적으로 문이 다시 열린 시도는 횟수 제외(11-06 답변 06) |
| 레버 점유·과적 안내 경합 | 과적 경고·덜컹 연출 우선. 다른 사람이 이미 레버를 잡았으면 안내 없이 한 건만 수락(11-06 답변 06) |

유효 회수는 회수 목록에 있고 지상에 도착한 것만이며, 문 닫힘 뒤 새로 실린 것과 상승 중 밖으로 빠진 것은 인정하지 않는다. 생존 귀환자가 0명이면 전멸이며 1차로 올린 판매용 회수품까지 사라진다(마지막 생존자가 엘리베이터 안에서 죽어도 전멸). 11-06 답변 03의 다음 탐사 기준(팀 승인 전): 갱도·던전에 남은 장비와 시간 종료 때 과적 사출된 편의 장비는 사라진다. 이미 지상에 도착했거나 문이 닫혀 상승 중인 편의 장비는 남는다. 캐릭터·시체 무게는 0이며 엘리베이터 무게는 소지품과 화물로만 계산하고 단계로만 표시한다.

### 정산머신 납부

여러 명이 동시에 각자의 돈자루를 들고 정산기 입구를 조준해 우클릭을 유지하면 금화를 붓는다. 목표액과 달성 여부는 공개하고, 공동 인정액은 정산기 외부 3색 신호기로만 보여 준다(시험 경계: 빨강 0~50% 미만, 주황 50~80% 미만, 초록 80~100% 미만, `PAY_SIGNAL_THRESHOLDS`). 정확한 누적 금액·개인별 잔고와 납부 상세는 공개하지 않는다. 달성 순간 신호기가 꺼지고 금괴가 거점 우물로 떨어진 뒤 새 사이클 색으로 다시 켜진다. 목표를 넘는 금화는 정산기 앞 바닥에 떨어지며 누구나 E로 주워 자기 잔고에 넣는다. 새 목표에 합산하지 않고 이미 인정된 납부의 환불은 없다. 인정 비율이 100% 미만일 때 바닥에 떨어질 금화 계산은 PQ-34, 정수·나머지 처리는 D27이다. 구현(자동 테스트 통과, M2·연출 미검증): 서버 Tick에서 레버보다 먼저 처리, 한 주기 `PAY_UNIT_AMOUNT` 10(임시, 첫 차감은 누른 뒤 간격이 지난 시각), 신호기만 공개(누적 금액은 복제하지 않고 HUD도 신호기 단계), 초과 금화는 PQ-34 안 A(목표에 필요한 최소 금화만 쓰고 나머지는 바닥 더미)로 시험(11-06 답변 02는 담당 답변 전 시험 계산 사용 허용, 최종 아님), 바닥 금화는 거점 저장 확장 v2에 저장. 입력 에셋(IA/IMC) 지정과 신호기 HUD 연결이 필요하다.

### 매몰과 게임 오버

매몰 단계는 붕괴가 덮치는 순간에만 1~3단계 중 무작위로 정한다. 추가 붕괴가 더 높은 단계면 갱신하고 구조 게이지를 0으로 하며, 시간이 지나 단계가 오르지 않는다. 1·2단계는 느려진 이동으로 매몰 영역을 벗어나 해제하고(자력 탈출 키·게이지 없음), 3단계는 이동할 수 없어 동료가 조준 후 E를 유지해 구한다(맨손 가능, 한 대상에 한 명). **3단계 매몰 즉사 기준은 실제 출발 인원(거점 문 닫힘 완료 시 확정) 1명**이며 방 인원·현재 활동 인원으로 판정하지 않는다. 시체 운반 중 구조 시도는 거절한다(11-06 답변 12).

게임 오버는 4일차 미달 마감 뒤 다음 순서로 진행한다. 11-06 답변 08은 귀환 저장을 먼저 하고 조작을 복구하는 순서를 유지했다(팀 승인 전).

1. 4일차 탐사 종료 → 즉시 5일차 → 검은 개인 정산 화면(본인 결과만, 조작·메뉴 잠금, 다시 열 수 없음)
2. 거점 귀환·부활 → 귀환 자동 저장(게임 오버 확정 포함) → 조작 복구
3. 실패 사건: 우물 범람 → 거점 침수 → 깊은 우물로 흡입. 각자 이동·시점 조작을 유지하며 공통 컷신 없음. 먼저 흡입된 사람은 기다리고 떠난 사람은 기다리지 않는다
4. 현재 참가자 전원이 함께 결과 크레딧(원근 스크롤). 빨리감기는 호스트만 조작하고 모두에게 같은 속도로 적용, 건너뛰기·일시정지·다시 보기 없음, 방 나가기·앱 종료 허용
5. 현재 사용한 슬롯만 새 게임으로 초기화하고 같은 방의 새 거점으로 이어진다(다른 슬롯 유지, 새 슬롯 자동 생성 없음)

크레딧은 전체 총액 → 획득 금액(히든 포함) → 히든 슬롯으로 얻은 금액 → 사망으로 잃은 금액 순서로 보여 준다. 각 블록 안은 참가 순서대로 “이름: 금액”을 나열하고 순위를 매기지 않는다. 0원인 사람과 중간에 나간 사람도 표시한다(11-06 답변 08, 팀 승인 전). 별도 실패 안내 화면 여부와 연출 세부는 D15다. 히든 수익은 크레딧에서만 공개한다.

구현(자동 테스트 통과, M2·연출 미검증): 위 1·3·4·5 순서와 2의 귀환 자동 저장 요청(게임 오버 확정 포함, 서버가 게임 오버 흐름을 시작할 때 요청하며 실패해도 진행을 막지 않음. 저장 완료 뒤 조작을 복구하는 순서는 M2에서 확인하지 않았다), 서버가 우물 거리 기준으로 흡입 시각을 정하고 마감 시각에 남은 사람은 강제 흡입, 떠난 사람은 기다리지 않음, 크레딧 재생은 서버 시각에 맞춰 모두 같고 호스트만 빨리감기, 새 게임은 현재 슬롯에서 1회만 실행(새 GameId, 이전 결과 보관 10개 임시). 지갑에 누적 통계(획득·히든·사망 손실 순액)를 추가했다. 연출 길이 `GO_*`는 모두 임시값이다. 우물 Actor 배치, 크레딧 WBP, 침수·흡입 연출 BP가 필요하다. 결과 크레딧 시작 때 전원 음성으로 바꾸는 수신 제한 전환은 2026-11-06 음성 1차 구현에 들어갔다(실제 음성은 M3 미검증).

### 분배 원칙

일반 화물 T를 출발 인원 N으로 나눈 몫은 내림하며 생존자에게만 지급한다(11-06 답변 03: 현 기준 유지, 분배·비율 최종 결정은 시험 후). 사망 손실 100%·유효 시체 회수 시 사망 직전 잔고의 50% 복구(소수점 버림)를 유지한다. 향후 손실률을 바꾸더라도 복구 계산 기준은 실제 손실액이 아니라 사망 직전 잔고로 둔다. 죽은 사람의 몫과 나머지는 분배하지 않는다. 죽은 사람의 장비와 히든 물건은 떨어지며 장비에는 귀속 소유권이 없다. 수익·손실과 시체 복구를 분리하고 동일 탐사의 재처리는 중복 지급하지 않는다. 예외(2026-11-08 몬스터 기획서, 승인 전 초안): 미스터리 박스에 먹힌 플레이어는 시체와 소지품(일반·히든 슬롯·헤드랜턴·장비·들고 있던 회수품)이 모두 사라진다. 떨어지는 물건이 없고 시체 회수와 50% 복구도 불가능하며, 이 예외가 위 시체·드롭 규칙보다 우선한다([반영 기준](planning/MONSTER_DESIGN_2026-11-08.md)).

### 비교용 탈출 시점형 분배

2026-11-04 기획 답변(초안, B3)은 플레이테스트 비교용으로 이전 방식인 탈출 시점형을 설정에서 고를 수 있게 요청했다. **기획 답변의 비교 요청이며 시스템 작업리스트 1.1.0에는 반영되지 않았다**(작업리스트 D16은 합산형만 적는다). 기본은 위 합산형(D16 시험 방식)이고 이 절은 비교 기준으로만 둔다.

- 화물은 엘리베이터 편 단위로 나눈다. 한 편에 실려 올라간 일반 화물을 하나로 묶으며, 손이나 인벤토리에 들고 탄 회수품도 그 편 화물이다.
- 나누는 사람 수 = 출발 인원 − 그 화물보다 먼저 탈출한 사람 수. 죽은 사람도 나누는 수에 포함한다. 받는 사람은 그중 끝까지 살아 돌아온 사람이며 죽거나 실종된 사람의 몫은 사라진다.
- 먼저 탈출한 사람은 자기가 나간 뒤 올라온 화물 몫을 받지 않는다. 2차로 탈출한 사람은 1차 화물 몫도 받는다.
- 1인 몫은 소수점을 버리고 남는 금액은 사라진다. 지급은 탐사가 완전히 끝난 뒤 한 번에 한다. 받을 생존자가 없는 화물은 지급하지 않는다.
- 순서 기준: 일반 편은 문이 완전히 닫혀 탑승 목록이 고정되는 순간, 긴급 탈출은 관전자로 바뀌는 순간이다. 긴급 탈출로는 회수품을 가져갈 수 없고, 목록 고정 전에 긴급 탈출한 사람은 그 편 화물 몫을 받지 못한다.
- 사출된 편(제한 시간 종료 시 무게 초과)과 출발이 취소된 편의 화물은 정산에서 뺀다. 평소 운행 중 문이 닫히다가 무게 초과로 다시 열린 시도는 편으로 세지 않는다. 제한 시간 종료 시 무게가 정상이면 그때 탄 사람과 화물로 자동 귀환편을 만들고 한 편으로 계산한다.

| 예시(4명 출발) | 진행 | 탈출 시점형 | 합산형(현재) |
|---|---|---|---|
| Q01 | 1차 A와 600 → B 긴급 탈출 → 2차 C와 300, D 사망 | A 150 / B 150 / C 300 | A·B·C 각 225 |
| Q02 | 1차 A와 600 → B가 120을 내려놓고 긴급 탈출 → C가 주워 2차로 300과 함께 탈출(2차 420), D 사망 | A 150 / B 150 / C 360 | A·B·C 각 255 |
| Q03 | B 먼저 긴급 탈출 → 1차 A와 600 → 2차 C와 300, D 사망 | B 0 / A 200 / C 350 | A·B·C 각 225 |
| Q04 | 1차 A와 600 → B·C·D 사망 | A 150(450 소실) | A 150 |

계산 예: Q01의 1차 600은 아직 아무도 탈출하지 않아 4명으로 나눠 150씩이며 A·B·C가 받고 D 몫은 사라진다. 2차 300은 A·B가 먼저 탈출해 C·D 2명으로 나눠 150씩이고 C만 받는다(C = 300). Q03의 1차 600은 B가 먼저 탈출해 A·C·D 3명으로 200씩, 2차 300은 C·D로 150씩이다(B 0, C 350).

비교: 탈출 시점형은 편마다 나누는 사람 수가 달라 규칙이 복잡하고 순서 기록·판정 작업이 늘어난다. 합산형은 총액 ÷ 출발 인원 한 번이지만 일부러 1차로 안전하게 올라가는 플레이가 반복될 수 있다. 동료가 죽었을 때 내 몫이 그대로이고 그 몫이 사라지는 점은 두 방식이 같다.

## 콘텐츠와 선택 범위

11-06 답변 기준(팀 승인 전): 배터리·연료·충전과 제단 헌납은 MVP에서 쓰지 않는다. 침대는 회복 없이 쉬기·교류용이고 탐사에서 잃은 체력은 갱도에서 거점으로 귀환할 때 초기화한다. 시험 목적지 유적·수정은 정식 갱도로 교체하며 정식 이름·목록·해금비는 추측하지 않는다. 장비·소모품 목록·이름·표시·가격은 11월 18일 콘텐츠 1차 확정 때 전달 예정(세부 수치 제외)이다. 갱도↔던전은 로딩 없이 이동한다. 던전 지정 벽 파괴는 플레이어·몬스터 모두 레벨 디자이너 결정 전 보류하며, 미채택 시 몬스터는 다른 길을 찾거나 기다린다. 설치 장비 밑의 지형이 없어지면 파괴하지 않고 떨어뜨려 재사용할 수 있게 한다. 갱도·던전에 끼거나 맵 밖으로 나간 장비는 탐사 종료 때 제거하고, 거점 물품은 불러올 때 엘리베이터 안으로 복구한다. 지원 언어는 출시 범위 결정 때 정한다.

폐교와 피라미드 던전은 기존 기획 방향이다. 아이템·경제 데이터(D22)는 작성 중이고, 최초 몬스터는 땅거미·미스터리 박스로 답변됐고 2026-11-08 기획서(승인 전 초안)로 상세를 받았으나 작업리스트 D23은 선정 대기다(PQ-17). 사다리·무전기·함정 등의 선택 기능은 개별 채택 전 범위에 넣지 않는다. 산소, 차량, 날씨, 전투 전용 무기, 엘리베이터 성능 업그레이드는 현재 채택 범위가 아니다. 장비의 공격과 팀킬은 포함한다. [결정 목록](planning/DECISIONS.md)과 [검증 계획](verification/VERIFICATION_PLAN.md)을 따른다.

기존 DG-001~019는 이전 기획 추적 ID이며 새 S ID로 자동 치환하거나 승인을 추정하지 않는다. 관련 Notion 요구의 실제 URL·개정과 기획 승인 상태를 확인한 뒤 연결한다.
