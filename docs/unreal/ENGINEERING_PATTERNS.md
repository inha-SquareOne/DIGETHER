# Unreal 엔지니어링 패턴

코드 표기는 프로젝트의 코딩 컨벤션을, 시스템 책임은 프로젝트의 아키텍처를 따른다. 공통 안전 기준과 프로젝트가 선택할 설계 패턴을 구분해 적용한다. 엔진·플러그인·타깃의 실제 지원 여부는 프로젝트 프로필과 소스로 확인한다.

## 수명과 비용

- Tick은 매 프레임 처리가 필요할 때만 쓰고 유휴 상태에서는 끈다.
- Actor/Component 탐색은 초기화·관계 변경 때 캐시하고 Tick에서 반복하지 않는다.
- 타이머·델리게이트·비동기 요청은 중복 실행을 막고 EndPlay·월드 전환·세션 종료 때 정리한다.
- UObject 참조 수명과 월드 유효성을 확인한다. 로컬 참조와 네트워크 소유권을 혼동하지 않는다. 비동기 결과 적용 전에 대상 객체·월드·요청 세대가 여전히 유효한지 확인하고, 해당 API가 허용한 스레드에서만 엔진 객체를 다룬다.
- 비용이 큰 작업(캡처, 경로 재계산)은 매 프레임이 아니라 필요할 때 하고 결과를 캐시한다.

## 상태와 경계

- 상태 변경은 단일 소유자가 수행하고 다른 시스템은 확정 이벤트를 구독한다.
- 동시에 참일 수 없는 상태를 불리언 여러 개로 표현하지 않는다. enum 상태머신으로 두면 "둘 다 참" 상태가 생기지 않는다.
- C++과 Blueprint의 역할은 프로젝트가 정한다. 어느 언어로 구현하든 판정·복제 상태의 소유자와 요청 경계를 지키고, 클라이언트 표현이 권위 상태를 직접 변경하지 않게 한다.
- 이벤트는 타입이 있는 델리게이트로 전달한다. 문자열 키 이벤트는 오타가 컴파일에 잡히지 않고 구독자를 추적할 수 없다.
- 모듈 경계는 빌드 의존을 제한할 뿐이다. 서버 권위는 런타임 검사·RPC 소유권·다인 테스트로 검증한다([네트워크 권위](NETWORK_AUTHORITY.md)).
- 결정론이 필요한 로직은 엔진 월드·UObject 의존을 피한다. 의존을 끊어도 결정론이 보장되지는 않으므로 시간·전역 난수·컨테이너 순회 순서와 시드 재현성을 테스트로 확인한다.

## 빌드 구성

- `!UE_BUILD_SHIPPING`은 Shipping 제외 조건이며 Development만을 뜻하지 않는다. `WITH_EDITOR`는 에디터 코드의 조건이다. 개발 도구·치트·테스트·에디터 기능은 목적에 맞는 모듈·타깃·가드를 선택하고 지원할 구성에서 포함 여부를 확인한다.
- 출시 빌드에서 빠지는 블록에 필수 게임 상태 변경이나 오류 처리를 넣지 않는다.
- 가드를 바꾸면 Development와 Shipping 양쪽에서 빌드한다.
- 헤더·모듈 의존을 바꾸면 non-unity 빌드로 숨은 의존을 확인한다. 환경이 없으면 미검증으로 남긴다.
- 에디터에서의 증분 컴파일만으로 독립 빌드나 패키징 성공을 주장하지 않는다. 리플렉션·직렬화 구조·플러그인 의존 변경은 에디터 재시작 후 빌드·기존 에셋 로드까지 확인한다.

## 성능

성능 개선은 Unreal Insights 등 실제 측정 근거로 진행한다.
프레임·대역폭 목표를 코드 모양만 보고 달성했다고 주장하지 않는다.

## 엔진 기본값을 고르기 전에

아래는 Unreal에서 흔히 기본으로 고르는 기능이다. 쓰지 말라는 것이 아니라, 프로젝트의 규모·사양·구조에 맞는지 정하고 이유를 아키텍처에 적으라는 것이다.

| 기능 | 정할 것 |
|---|---|
| World Partition·런타임 레벨 스트리밍 | 맵 크기가 필요로 하는가. 게임의 가시성·통행 토글과 같은 액터를 두고 다투지 않는가 |
| Nanite·Lumen | 최소 사양 예산에서 성립하는가. 기본 경로가 이것 없이 도는가 |
| 오브젝트 풀 | 엔티티 수가 풀의 생명주기 복잡도를 감수할 만큼 많은가 |
| AIPerception | 기본 감지 기능·확장과 직접 구현 중 규칙·성능·데이터 조정 요구를 충족하는 것은 무엇인가 |
| Pawn 교체·Spectator 전환 | 원래 몸이 그 자리에 남아야 하는 규칙이 있는가 |
| Mass Entity | 이 규모에서 액터 복제와의 결합 비용을 넘는 이득이 있는가 |
| 원격 설정 | 운영할 서버가 있는가 |

정한 것과 다르게 가야 하면 변경 설명에 규칙·범위·이유·후속 검증을 남긴다.
