# 에셋·데이터 정책

자체 코드·기획은 요청 범위에서 다룬다. 구매 에셋 원본·계정·토큰·개인정보를 외부 AI에 업로드하지 않는다.
외부 에셋 오류는 자신의 호출 코드·오류 메시지·공개 API 설명으로 조사한다.

## 출처와 라이선스

외부 에셋마다 출처, 제작자, 취득일, 라이선스 원문, 상업 이용·재배포 조건을 프로젝트의 라이선스 기록에 남긴다.
AI 생성물은 도구·생성일·사용 조건·후처리·검수 기록을 남긴다.
스토어 출시 시의 AI 콘텐츠 공시 요구는 그 시점의 공식 정책으로 확인한다.

## 원본과 임포트 결과

원본(모델·텍스처·음원)의 보관 위치는 프로젝트가 정한다. 정해지지 않았다면 원본을 무조건 Git에 넣거나 로컬에만 있다고 가정하지 않는다.
게임 실행에 필요한 임포트 결과는 라이선스 허용 범위에서 프로젝트가 정한 소스 관리·대용량 파일 방식으로 추적한다. Git LFS를 쓰는 경우 실제 파일 확보와 원격 지원까지 확인한다([레벨·에셋 안전](../unreal/ASSET_SAFETY.md)).
폴리곤·텍스처·머티리얼·라이트맵 UV 예산은 프로젝트의 렌더링 기준으로 검수한다.

## 비밀값

서비스 자격증명, 플랫폼 관련 비밀값, 실제 계정 정보는 문서·설정 파일·로그·커밋에 넣지 않는다.
.env·로컬 설정은 ignore 여부를 확인하고 사용한다. 공개 식별자와 비밀값을 구분한다.
스크린샷·영상에는 계정·알림·토큰이 노출되지 않도록 확인한다.
유출 시 추가 전송을 중단하고 값 자체를 재노출하지 않은 채 위치·범위를 보고한다. 비밀값 폐기·재발급은 해당 계정 권한과 승인 범위 안에서 진행하거나 담당자에게 요청한다. ignore 추가나 파일에서의 제거만으로 기존 유출이 해소됐다고 보지 않는다. 임의로 Git 이력을 재작성하지 않는다.
