# Meshy 도구 지원 확인

원본 워크플로의 특정 CLI 버전·옵션은 이 패키지에서 지원을 검증하지 않았다. 다음 절차는 실행할 때 현재 설치 도구와 계정을 확인하기 위한 것이다.

1. 이미 제공되는 연결 도구의 설명·스키마 또는 설치된 CLI의 버전과 도움말을 읽는다. 도구를 찾는 과정에서 키·토큰·개인 설정 값을 출력하지 않는다.
2. 필요한 생성/편집/조회/다운로드 기능과 입력 형식, 비동기 작업 상태, 비용 표시·제한 기능을 확인한다. 지원 여부를 확인하기 전에는 명령·옵션·가격을 작성하거나 실행하지 않는다.
3. 불명확한 기능은 [Meshy 공식 문서](https://docs.meshy.ai/)에서 해당 API/도구 버전으로 확인한다. 문서가 API를 설명한다고 해서 설치 CLI도 같은 옵션을 지원한다고 가정하지 않는다.
4. dry-run이나 비용 상한 옵션도 실제 도움말에서 확인된 경우에만 사용한다. 이름만으로 무과금 동작을 보장하지 않는다.
5. 작업 생성과 조회를 구분한다. 결과 불명확 시 기록된 작업 ID로 조회하고, 중복 생성을 피한다. 상태 조회 주기·제한은 현재 도구의 규칙을 따른다.
6. 인증 또는 서비스 접근이 없으면 필요한 연결을 명시한다. 임의 설치·유료 작업·인증 우회는 하지 않는다.

이 패키지 제작 과정에서는 Meshy 유료 작업, 모델 생성 또는 Unreal import를 실행하지 않았다.
