# AI 작업 규칙

프로젝트의 루트 진입 지침과 최신 요청을 먼저 확인하고 해당 작업의 기준만 읽는다. 프로젝트가 채운 사람용 문서는 [문서 지도](../common/DOCUMENT_MAP.md)에서 찾는다.

| 작업 | 기준 |
| --- | --- |
| 시작·승인·복구 | [실행 정책](EXECUTION_POLICY.md) |
| 담당 경계·기존 변경·잠금 | [작업 경계](WORK_BOUNDARIES.md) |
| 목표와 완료 기준 | [작업 브리프](TASK_BRIEF.md), [요구사항 분석](REQUIREMENTS_ANALYSIS.md) |
| 증거와 검사 | [검증](VERIFICATION.md), [TDD](TDD.md), [멀티플레이](MULTIPLAYER_TEST.md) |
| 재개·대형 문맥 | [문맥 관리](CONTEXT_HYGIENE.md), [인계](SESSION_HANDOFF.md) |
| 승인된 분담·긴 작업 | [작업 분담](WORK_ORCHESTRATION.md), [단계별 작업](MULTI_STAGE_WORKFLOW.md) |
| 외부 자료·모델 제작 | [에셋·데이터 정책](ASSET_AND_DATA.md), [Meshy 도구 확인](MESHY_TOOLS.md) |
| 문서 작성·갱신 | [사람용 문서 관리 기준](../common/DOCUMENTATION_POLICY.md) |
| 역할별 지침 | [역할 안내와 본문 링크](../common/AGENTS_OVERVIEW.md) |
| Unreal 기술 작업 | [Unreal 기준](../unreal/README.md) |

스킬 선택이나 역할 정의의 존재는 수정 범위·외부 실행·위임 권한을 새로 부여하지 않는다.

질문·답변과 결과 보고는 [응답 방식](RESPONSE_STYLE_GUIDE.md)의 결론 우선·근거·미검증 구분을 따른다.
