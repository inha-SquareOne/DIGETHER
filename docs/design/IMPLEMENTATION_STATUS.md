# 구현 현황

기준일: 2026-11-10 (커밋 ee12223, `feature/minsung`), 몬스터 행은 2026-11-11, 음성 행은 2026-11-12 구현·검증 결과로 갱신했다. 도메인별 **코드 유무·자동 테스트 등록 수·실행으로 확인한 범위·미검증**을 한 곳에 모은다. 설계 문서는 현황을 본문에 다시 적지 않고 이 문서를 링크한다. 기능 상태가 바뀐 작업 안에서 해당 행을 갱신한다.

읽는 법:

- "코드 있음"은 소스가 저장소에 있다는 뜻이다. 동작 확인은 '실행으로 확인한 범위' 칸만 근거로 삼는다.
- 테스트 수는 2026-11-10에 소스의 등록 이름을 센 값이다. 몬스터 6개(2026-11-11)와 음성 9개(2026-11-12)는 에디터의 발견·실행 결과다. 다른 행의 등록 수를 이번에 다시 센 것은 아니다.
- 실행 확인은 확인한 날짜의 사실이다. 그 뒤 코드가 바뀐 도메인은 다시 확인해야 한다. 상세 증거는 작업자 로컬의 날짜별 작업 기록에 있으며 Git에는 없다.
- 다인 검증 등급 M0~M3는 [멀티플레이 테스트](../ai/MULTIPLAYER_TEST.md), 검사 항목은 [검증 계획](../verification/VERIFICATION_PLAN.md)을 따른다.
