# ADR-001: 기획과 프로젝트 파일의 원본 분리

- 상태: 채택, 사용자 명시 요청
- 날짜: 2026-10-23
- 결정: 기획은 Notion, 프로젝트 파일 관리는 GitHub
- 근거: 이 작업의 사용자 요청. 저장소 origin은 inha-SquareOne/DIGETHER로 확인됨

기획 편집과 코드·에셋 변경 검토를 각 도구에서 수행한다. 같은 기획을 양쪽에서 별도로 최신본처럼 편집하면 차이가 생기므로 원본 URL·개정·요구 ID로 연결한다. 대안인 GitHub 단독 기획이나 Notion의 프로젝트 파일 원본화는 현재 사용자 결정과 다르므로 채택하지 않는다.

현재 로컬 Notion 가져오기 파일은 이관 전 초안이다. 페이지 생성 후 [문서 운영](../DOCUMENTATION.md)의 이관 확인을 거쳐 스냅샷으로 전환한다. Issue/PR을 개발 진행 원본으로 사용하는 세부 절차는 제안이며 아직 온라인 설정되지 않았다.

재검토 조건: 팀 도구 변경, 접근 불가가 지속됨, 승인 개정 추적에 반복 오류 발생. 변경 시 이 ADR을 조용히 덮어쓰기보다 후속 결정과 연결한다.
