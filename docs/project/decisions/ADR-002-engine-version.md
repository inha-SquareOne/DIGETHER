# ADR-002: Unreal Engine 5.8.2

- 상태: 채택, 사용자 명시 요청
- 날짜: 2026-10-23
- 결정: DIGETHER 엔진 버전은 **5.8.2**
- 근거: 문서 작성 중 사용자가 "엔진은 5.8.2를 사용할거야"라고 지정

문서와 이후 환경 준비의 기준을 동일 버전으로 맞춘다. 사용자 지정이 선택 이유이며 다른 버전 대비 성능·기능 우위를 조사해 선택한 것은 아니다. 설치 방식·지원 SDK·플러그인·플랫폼 호환성은 이번에 검증하지 않았다.

다른 버전으로 임의 대체하거나 자동 업그레이드하지 않는다. 실제 준비가 불가능하거나 필수 의존이 호환되지 않으면 근거와 대안을 기록해 엔진 변경 결정을 받는다. 설치 검증 후 [프로필](../PROJECT_PROFILE.md)과 [온보딩](../ONBOARDING.md)을 갱신한다.
