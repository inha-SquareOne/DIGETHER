# DIGETHER 게임 기획

기준일: 2026-10-23 · 상태: Notion 이관 전 초안 · 담당/승인자: 미정.

게임 기획 초안이며 구현 완료·팀 최종 승인·기술 검증을 의미하지 않는다. 사용자 확정은 UE 5.8.2, Notion 기획, GitHub 프로젝트 파일 관리다.

## 플레이 경험과 대상

“길은 함께 파고, 돈은 각자 챙기는 협동 굴착 호러”. 1~4인 온라인 협동 호러이며 굴착·탐험·던전·파밍·협동과 개인 재화를 중심으로 한다. 주 타겟은 친구와 협동 호러를 즐기는 2~4인 그룹, 핵심 유입층은 Lethal Company와 R.E.P.O. 장르 경험자다.

실수·구출·협상·갈등이 런 중 발생하는 경험을 목표로 한다. 스트리머와 클립을 통한 확산은 **전략 가설**이다. 확산 채널 언급은 출시 플랫폼 확정이 아니다. 출시 플랫폼, 입력 장치, 세션 길이, 목표 성능은 미정이다.

## 플레이 루프

1. 로비에서 장비를 구매한다.
2. 갱도를 굴착하며 길을 만든다.
3. 포탈 너머 던전에서 벽을 파괴하고 회수품을 탐색한다.
4. 귀환 중 붕괴에 깔린 동료를 구출한다.
5. 엘리베이터 무게 제한 안에서 회수품을 선택해 탈출한다.
6. 회수품을 개인 정산하고 장비 구매·할당량 납부를 진행한다.
7. 1~4일차를 반복한다. 4일차 종료에 할당량을 달성하면 더 높은 할당량으로 1일차를 다시 시작하며, 미달하면 게임 오버다.

성공 시 할당량 상향·실패 시 게임 오버·재시작 분기는 기획 검토가 필요하다. 런·일차의 경계, 전원 사망과 중도 이탈 처리, 게임 오버 후 초기화 범위는 미결이다.

## 콘텐츠·아트 상세 방향

폐교는 익숙함에서 오는 공포, 반복적인 격자 구조, 음악실·미술실·과학실·화장실 등 다양한 공간을 지향한다. 피라미드는 탐험욕을 자극하는 미로·트랩·기믹 구조를 지향한다. 이 공간들이 모두 구현되어 있다는 뜻은 아니다.

캐릭터는 굵은 외곽선과 단순한 면 분할, 맵은 외곽선·해칭 음영·낮은 채도, 몬스터는 잉크 선 질감과 큰 실루엣을 참고한다. 소규모 팀 제작과 굴착 지형 표현을 고려한 방향이다. 레퍼런스 이미지의 권리나 실제 게임 에셋 사용 허가는 별도 확인한다.

## 범위와 미결

최초 완성 범위는 1~4인 온라인 굴착·운반·개인 정산, 외부 갱도 맵, 폐교·피라미드, 몬스터·아이템이다. 추가 던전·몬스터·아이템은 최초 범위 완성 이후 확장 방향이다. 구체적 개수·일정·담당·플랫폼·서버 방식은 이 문서에서 확정하지 않는다.
