# DIGETHER 마일스톤

기준일: 2026-10-23 · 상태: Notion 이관 전 초안. 시작일·완료일·실제 담당자·공수는 모두 미정이다. 단계 정의는 기획 초안이며 아래 완료 관찰 및 요구 배치는 **검토 제안**이다. 구현·검증 완료를 주장하지 않는다.

## 단계 전환 검토 제안

- M1→M2: 핵심 기술의 실행 근거와 선택 이유를 남기고, 남은 위험이 전체 콘텐츠 제작에 주는 영향을 확인한다. 문서 작성만으로 기술 검증 완료 처리하지 않는다.
- M2→M3: 최초 범위의 통합 흐름을 재현하고 미구현·미확정 기능을 명시한다. 통과 성능 기준·지원 플랫폼·테스트 환경은 D-003/D-011 결정 후 적용한다.
- M3 이후: 베타 종료와 출시 승인을 동일시하지 않는다. 출시 기준·배포 방식·운영 범위는 실제 결정이 필요하다.

각 단계의 요구 배치는 담당자·기술 조사 후 조정한다. 달력 날짜와 작업자 배정은 Notion 마일스톤 DB에서 실제 합의 뒤 입력한다.

## 최초 범위 이후

추가 던전·몬스터·아이템은 최초 범위 완성 후 확장 방향이다. 추가 콘텐츠를 현재 마일스톤의 필수 완료 조건으로 자동 포함하지 않는다. 변경 시 기획 결정과 영향을 연결해 범위를 다시 합의한다.

## 검증 기록 최소 형식

테스트 ID / 요구 ID / 빌드·커밋 / 실행 환경 / 참여 인원 / 선행 상태 / 절차 / 기대 결과 / 실제 결과 / 증거 / 결함 링크. 현재 실행 결과는 없으며 테스트 통과 여부는 미확인이다.
