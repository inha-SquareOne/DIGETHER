# DIGETHER 결정과 미결 사항

기준일: 2026-10-23 · 상태: Notion 이관 전 초안 · 문서 검토·관리 담당: 미정. 사용자 확정, 게임 기획 방향, 문서 작성상의 제안을 분리한다. 결정 ID는 이 기획 패키지 내 식별자다.

## 확인된 사용자 결정

| ID | 결정 | 근거 | 영향 및 남은 확인 |
| --- | --- | --- | --- |
| D-001 | 기술 결정 참조 | [ADR-002](../decisions/ADR-002-engine-version.md) | 결정 본문과 상태는 ADR 원본을 따름 |
| D-002 | 운영 결정 참조 | [ADR-001](../decisions/ADR-001-document-ownership.md) | 결정 본문과 상태는 ADR 원본을 따름 |

위 결정의 대안 검토나 채택 이유는 사용자 발언에 없으므로 추가로 만들어 기록하지 않는다. 변경이 필요하면 실제 승인 근거와 대체 결정 ID를 보존한다.

아래는 기준일 현재 결정을 기다리는 질문의 색인이다. 기획 질문의 상태는 Notion에서 관리한다. 기술·운영 질문의 결정과 상태는 GitHub의 구조·운영 문서 및 채택 시 ADR에만 기록하며, 이 색인에는 요구·질문·링크를 유지한다. 혼합 항목은 기획과 기술 하위 질문을 나눠 각 원본에서 관리한다. 실제 담당·기한은 미정이다.

## 결정 기록 양식

결정 ID / 제목 / 상태(제안·승인·폐기·대체) / 작성일과 실제 결정일 / 실제 결정자·참여자 / 연결 요구 / 문제·제약 / 검토한 대안과 근거 / 결정·이유 / 영향 / 재검토 조건 / 승인 근거 / 대체 관계.

검토한 적 없는 대안을 검토 완료처럼 기록하지 않는다. 수치가 확정되면 단위·근거·실행 데이터 위치를 연결한다. 작은 편집과 기획 변경을 구분하고 승인된 결정도 구현 완료와 별도로 추적한다.
