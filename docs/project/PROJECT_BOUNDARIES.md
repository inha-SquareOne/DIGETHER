# 담당과 작업 경계

기준일: 2026-10-28. 기획 역할을 정리했으며 GitHub 계정·코드 소유권·최종 리뷰 권한은 별도 확인한다.

| 사람 | 자료에 명시된 역할 | 이 문서에서 자동 부여하지 않는 권한 |
|---|---|---|
| 김민재 | 팀장, 방향성 조율·콘텐츠·시스템 기획 | 저장소 관리자·모든 PR 승인 |
| 정경환 | 부팀장, 레벨·레벨 콘텐츠·레벨 시스템 기획 | 공유 맵 독점 편집·통합 권한 |
| 강준혁 | 시나리오·콘텐츠/시스템 보조·게임 경제 | 경제 코드 소유자 |
| 김하은 | 시나리오·콘텐츠/시스템 보조·일정 관리 | 릴리스 승인·개발 일정 확정 |

## 경로별 초기 경계

| 영역 | 현재 상태 | 작성/통합/리뷰 담당 | 필요한 합의 |
|---|---|---|---|
| Notion 기획 | 이관 전 초안 | 역할 참고, 최종 승인자 미정 | 문서별 소유자·개정 승인 |
| docs/project | 이번 문서 세트 생성 | 장기 유지·리뷰 담당 미정 | 기획 변경의 기술 영향 반영 |
| docs/ai·docs/unreal·.agents/skills·.claude/skills·역할 사본 | 공통 자료 도입 | 공통 기준 관리 담당 미정 | 원본·사본 동기화 |
| Source·Config·Plugins·Build | `DIGETHER/Source`·`Config` 및 `Plugins/DevelopmentWorkbench`·`Plugins/DigetherWorkbench` 존재. Build는 생성물 여부를 작업 시 확인 | 미정 | 실제 모듈·공유 계약·빌드 책임 |
| Content 및 맵·외부 액터 | `DIGETHER/Content` 템플릿 에셋·맵 존재 | 미정 | 에셋별 작업자·잠금·통합 맵 책임 |
| 초보 지원·파일 전달 | 역할 지정 전 | 기술 지원·기획 전달 담당 미정 | 권한 요청, 첫 파일 전달, 오류 보존과 전달 지원 |
| .github 설정·CODEOWNERS | 미생성 | 미정 | 실제 계정·리뷰·보호 규칙 |

CODEOWNERS는 공통 예시만 있으며 활성 파일을 만들지 않았다. 리뷰 소유권은 파일 쓰기 권한이나 잠금이 아니다.

## 작업 배정과 인계 운영안

작업 시작 시 요구 ID, 담당, 쓰기 경로, 공유 계약/맵, 동시 편집 상태, 검증과 통합 담당을 Issue 또는 브리프에 적는다. 현재 없는 경로를 이미 생성된 것으로 적지 않는다.

같은 바이너리 에셋·공유 맵은 동시에 저장하지 않는다. 담당자가 편집 시작을 알린다. SVN 쪽 에셋·맵은 `svn:needs-lock` 잠금을 걸고 편집한다. 잠금이 없는 Git 쪽 로직 에셋은 명시적인 작업 예약을 사용한다([ADR-004](../decisions/ADR-004-git-code-svn-assets.md)). 인계에는 저장 여부·변경 목록·참조 검사·다음 편집 가능 시점을 남긴다.

AI 작업의 범위는 사용자가 요청한 파일/기능과 배정한 경로로 제한한다. 경계 밖 변경이 필요하면 영향과 이유를 기록하고 기존 승인 범위에서 해결 가능한지 판단한다. 팀 담당자를 임의로 배정하지 않는다. 긴급 수정·배포 권한과 사후 리뷰 기한은 아직 미정이다.

## 기존 사용자 작업 방향

이전 전체 시스템 설계 요청에서 작성 요청자는 무기 등을 포함한 핵심 게임 로직을 직접 구현하려는 잠정 방향을 밝혔다. 현재 기획의 전투 전용 무기는 범위 밖이며 장비 공격·팀킬은 포함한다. 이 방향은 다른 핵심 기능의 담당자 확정, 코드 소유권, 리뷰 권한 또는 AI의 게임 구현 승인이 아니다. 실제 작업자·경로와 공유 계약은 착수 시 합의한다.
