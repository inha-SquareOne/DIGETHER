# 2026-10-23 스킬 추가 검증

대상: 사용자 지정 Epic/Blender 저장소, BMAD 게임 스킬, 신시 유용 스킬의 프로젝트 로컬 설치. 이 기록은 [이전 문서 작성 검증](2026-10-23.md) 이후 변경에 대한 별도 기록이다.

## 결과

기존 14종 + 신규 68종 = 관리 원본 82종. Codex/Claude 발견 경로는 각각 82종(합계 164개 SKILL.md)이다. Unreal 역할 정의 7종은 그대로 유지했다. BMAD의 역할형 스킬을 별도 `.codex/agents` 역할로 임의 중복 등록하지 않았다.

| 검사 | 실제 결과·범위 |
|---|---|
| Epic/Blender 다운로드 | skill-installer를 커밋 SHA로 고정해 실행, 성공 |
| upstream 내용 비교 | 설치한 94개 지원 파일의 Git blob SHA-1이 조회한 고정 커밋 tree와 모두 일치 |

| Python 정적 검사 | skills 아래 68개 Python 파일 AST 파싱 성공. 전체 스크립트 기능 실행을 뜻하지 않음 |
| 신규/보강 스킬 검사 | create-game-vfx, register-vfx-prewarming, guided-issue, write-handoff, meshy-model-production 5종 quick_validate 통과 |

| BMAD 설정 | 중앙 resolve_config 성공, customization 제공 39개 resolve_customization 실제 성공, 41종 사본·카탈로그 경로 검사 성공 |
| Blender 환경 | 자동 탐지 및 `--version`: 5.1.0. 빈 백그라운드 프로세스 env_report가 ok=true로 종료 0. 사용자 blend 파일 미사용 |
| Git | `git diff --check` 종료 0. 아직 커밋·푸시하지 않음 |

전체 원시 계수·분류와 검증 한계는 [검증 JSON](../../../provenance/skill-install-validation.json), upstream 커밋/파일은 [외부 lock](../../../provenance/external-skills-lock.json), 이식 변경은 [신시 근거](../../../provenance/shinshi-skills.json), BMAD는 [설치 근거](../../../provenance/bmad-install/README.md)에 보존했다.

초기 검사에서 Python 런타임에 PyYAML이 없고 기본 cp949가 한국어 파일을 읽지 못했다. 전역 패키지/설정을 바꾸지 않고 `uv run --with pyyaml python -X utf8`로 검사했다. 사본 비교의 줄바꿈·문서/라이선스 상대 경로 정규화도 보정해 전체 재실행했다. 이는 스킬 본문 오류 수정과 구분한다.

## 독립 시나리오 검토

신시 VFX 2종에 대해 별도 읽기 전용 에이전트가 실제 저장소를 근거로 “붕괴 먼지 효과를 만들어 게임에서 보여 달라”, “완성 효과를 프리워밍 목록에만 등록해 달라”를 검토했다. 현재 없는 `.uproject`/에셋·카탈로그 경로를 발명하거나 문서/Blender 시안만으로 게임 실행 완료를 보고할 수 없음을 확인했다. 직접적인 Unreal/Notion 규칙 충돌은 없었다.

비전투 장식 효과에도 전투 예고·서버 확정 검사를 강제하는 듯한 표현을 지적받아 “효과의 실제 계약에 해당하는 항목만” 적용하도록 수정했다. 실제 VFX 제작·게임 재생·프리워밍 실행 테스트는 하지 않았다. 신규 게임 아키텍처 설계가 아니라 스킬 설치·이식 작업으로, 별도 Claude 설계 교차 검증은 실행하지 않았다.

## 실행 한계

- Blender 스킬 upstream 기준은 **5.2 이상**, 설치된 Blender는 **5.1.0**. 환경 보고 성공은 전체 22종 호환 확인이 아니다. 설치 Blender는 변경하지 않았다.
- Unreal 5.8.2 프로젝트·ModelContextProtocol/AllToolsets·실제 MCP 도구 연결은 미검증이다. Claude plugin hooks·marketplace·MCP 서버 설정도 추가하지 않았다.
- BMAD 설정 해석 성공은 GDD 생성·개발·테스트·에이전트 호출·Notion 게시 성공이 아니다. 프로젝트 기획 원본 정책을 override와 진입 문서에 연결했다.
- 외부 스크립트 전체 기능/네트워크 동작을 실행 검증하지 않았다. 새 스킬의 런타임 발견은 다음 턴 또는 새 클라이언트 세션에서 확인한다.
