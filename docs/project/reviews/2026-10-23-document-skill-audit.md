# 문서·스킬 통합 점검 — 2026-10-23

## 요청과 범위

문서와 스킬의 중복·충돌을 정리하고 기획·아트·개발별 가이드 및 GitHub 초보 안내를 작성했다. 게임 규칙·기획 요구사항은 변경하지 않았다. 온라인 게시·GitHub 설정·에셋 편집은 하지 않았다.

기존 docs 68개, 역할 카탈로그와 어댑터 14개를 읽고 검토했다. 스킬은 83종의 진입 문서와 지원 파일 438개의 정책 문구·구조를 전수 검색하고 충돌 후보의 실행 절차를 검토했다. 기술 예제 전부를 엔진에서 실행한 검증은 아니다. 두 스킬 경로의 복제는 도구 발견에 필요한 동기화 사본으로 유지한다. 재사용 양식과 역할별 독립 안전 경계는 불필요한 중복으로 삭제하지 않았다.

## 검증

통합 정적 검사: docs 74개, 스킬 83종·지원 파일 438개 사본 일치, Python 73개 구문·TOML 87개·JSON 3개 파싱, BMAD 카탈로그 41개 경로, 요구 ID 19개 보존을 확인했다. 문서 실링크 377개·앵커 1개와 스킬 실링크 83개가 유효했다. 스킬 내부의 생성 예정 문서·예시 링크 22개는 실행 의존 경로가 아닌 양식 자리표시자로 구분했다. BMAD config resolver에서 `modules.gds.project_knowledge`와 한국어 설정을 읽었다. 83종의 스킬 형식 검사가 통과했다. `git diff --check`는 추적 파일 대상으로 통과했고, 미추적 문서를 포함한 Markdown 본문은 별도 UTF-8 읽기·링크·줄 끝 공백 검사를 수행했다.

실제 GitHub 사용자별 권한·LFS 설정·Desktop 조작·Unreal 실행은 검증 범위 밖이다.

## 독립 교차 검증과 반영

Claude Opus 5.5, effort `xhigh`, `--permission-mode plan`으로 읽기 전용 검증을 수행했다(종료 0). 높은 심각도 0건·중간 3건·낮음 8건을 받았고 11건 모두 수용했다. 검증자는 파일을 수정하지 않았다.

기각 항목은 없다. Desktop 잠금 UI는 미검증이므로 기술 담당이 실제 잠금·해제 방법과 초보 지원을 시험한 뒤 전달을 시작하도록 안내했다. 기본 운영 모델이나 문서 구조를 새로 바꾸지 않고 기존 절의 누락 조건·문구를 보완했으므로 Claude 재호출은 하지 않았다. 반영 후 작성자가 스킬 형식·사본·해시·구문·링크·요구 ID를 다시 검사했다. 독립 검증자가 최종 수정본을 재승인한 것은 아니다.
