캐릭터 조작·이동·스태미나·체력·낙하 피해·운반·매몰·사망 이후 처리를 다룬 기획서다. 기획서는 항목마다 **확정**(합의한 규칙), **시험값**(구현·플레이테스트 시작값, 최종 밸런스 아님), **제안값**(미채택), **확인 필요**를 붙였다. 이 구분을 그대로 옮긴다. 이 문서에 반영했다고 해서 Notion 승인, 구현, 플레이 수용이 끝났다는 뜻은 아니다.

함께 받은 `DIGETHER_시스템_작업리스트_1.1.0.xlsx`는 이미 반영한 1.1.0과 내용이 같다(작성일 2026-11-05, 16개 시트, 미정 D 16개, 인수 T01~T93, 튜닝 파라미터 129행). 이번에는 S03·D26·`PLY_*` 매핑의 대조 근거로만 썼다.

## 적용과 승인 경계

- 기획서는 매몰 구조·로비 사망과 부활을 **런 플로우 v1.1.0**에 따른다고 적는다. 같은 날 v1.1.0을 받아 [런 플로우 반영 기준](RUN_FLOW_2026-11-14.md)에 정리했고 매몰 구조·로비 부활 내용이 같음을 확인했다(PQ-46 해결). 로비 사망 잔고 손실 50%(잠정)·손실액 올림은 런 플로우에만 있다.
- 작업리스트 1.1.0(2026-11-05)과 다른 부분은 더 늦은 이 기획서를 현재 기획 기준으로 삼는다. 작업리스트의 S03·S10·T51과 튜닝 시트가 아직 고쳐지지 않았으므로 아래 [기존 기준과 바뀐 점](#기존-기준과-바뀐-점)에 적었다.
- 갱도 붕괴 선정·장비별 효과·몬스터 피해·경제 정산은 기획서가 각 상세 기획서로 넘겼다. 이 문서에서 추정해 채우지 않는다.
- 외형·애니메이션 시안과 UI 파일 전달 여부는 전달본을 따른다.

## 스태미나

달리기만 스태미나를 쓴다. 점프·굴착·공격·구조 자체는 소모하지 않는다. 회복이 소모보다 느리도록 둔다.

| 항목 | 기준 | 상태 |
|---|---|---|
| 최대 | 100 | 확정 |
| 음수 게이지 | 0 아래로 -20까지 달릴 수 있고 -20에서 달리기가 끝난다(고갈) | 시험값 -20 |
| UI 표기 | 0~100만 표시. 음수 구간은 빈 게이지(0)로 보임 | 확정 |
| 달리기 소모 | 실제로 달리는 동안 초당 10, 연속 감소. 공중에서도 달리기 상태면 같은 소모. 점프 자체 추가 비용 없음 | 소모 대상 확정, 초당 10은 시험값 |
| 회복 대기 | 마지막 실제 소모 후 2초 | 시험값 |
| 회복 속도 | 초당 5, 연속 증가, 최대 100. 음수 구간에서도 같은 속도 | 시험값 |
| 달리기 시작 기준 | 현재 스태미나가 0 초과 | 시험값 |

판정 규칙(확정):

- **시작**: 이동 입력 + Shift + 스태미나 0 초과 + 달리기 가능 상태를 모두 만족.
- **유지**: 시작한 뒤에는 0을 지나 음수로 계속 달리고 -20 전까지 유지.
- **일반 종료**: Shift 해제, 이동 종료, 달리기 불가 상태 진입.
- **고갈 종료**: -20에서 즉시 종료. 걷기·일반 점프는 가능.
- **재개**: 회복으로 양수가 된 뒤 Shift를 **새로** 눌러야 한다. 누르고 있는 것만으로 자동 재개하지 않는다. 음수 구간(예: -5)에서 멈춘 경우도 양수가 될 때까지 달릴 수 없다.
- **회복 대기 초기화**: 실제 소모만 대기를 다시 센다. 시작 실패한 Shift 입력, 걷기·정지·점프·굴착·공격·구조는 초기화하지 않는다. Shift만 누른 정지 상태는 소모하지 않는다. 소모와 회복은 동시에 적용하지 않는다. 고갈 전용 대기 시간은 없다. 매몰 중에도 같은 회복 조건을 적용한다.
- 고갈 후 흐름: 0초 -20(UI 0) → 2초 회복 시작 → 6초 0 → 직후 양수가 되면 새 Shift로 재달리기 → 26초 100.

초기화(확정):

| 시점·상태 | 처리 |
|---|---|
| 캐릭터 생성·부활·최종 로비 귀환 | 100으로 초기화 |
| 새 탐사 시작·최초 하강 | 초기화하지 않고 로비에서 쓰고 회복한 값을 이어감. 그 시점에 실제 부활이 일어나면 부활 초기화 적용 |
| 사망·관전 중(사망 관전, 1차·긴급 탈출 관전 모두) | 본인 소모·회복 계산 중단, 본인 게이지 숨김. 관전 진입만으로 최종 귀환 초기화를 앞당기지 않음 |

## 체력과 낙하 피해

| 항목 | 기준 | 상태 |
|---|---|---|
| 최대 체력 | 100 | 확정 |
| 탐사 중 자연 회복 | 없음(스태미나와 별도 자원) | 확정 |
| 최종 로비 귀환 | 탐사 중 잃은 체력 초기화 | 확정 |
| 로비 침대 | 체력 회복 기능 없음 | 확정 |
| 사망 | 체력 0 이하 | 기본 처리 |
| 일반 낙하 7m 이하 | 피해 없음 | 시험값 |
| 일반 낙하 7m 초과 | 피해 = (전체 낙하 높이(m) − 7) × 10. 예: 8m 10, 10m 30, 12m 50, 15m 80, 17m 100 | 채택 시험값 |
| 상승기류 역장 안에 착지 | 높이와 관계없이 낙하 피해 0 | 확정 |
| 역장 밖에 착지 | 역장 통과 전을 포함한 전체 낙하 높이로 계산 | 확정 |

- 역장은 낙하 피해만 면제하고 다른 피해 무적을 주지 않는다. 역장 점프 높이 4m(장비 시험값)와 낙하 안전 높이 7m는 별개 값이다.
- 착지 판정 위치·역장 경계·낙하 높이 측정·피해 반영 시점은 개발이 구체화해야 한다.
- 공격은 곡괭이 등 작업 장비로 굴착과 같은 버튼을 쓴다. 전투 전용 무기는 없다. 탐사 중 팀킬 허용, 로비 공격 피해는 0이다.
- **로비에서도 낙사·익사로 죽을 수 있다.** 낙하 피해는 탐사와 같다. 익사 판정 조건은 확인 필요(기획서 표기).
- 공통 피격 무적·경직과 로비 넉백 등 부수 효과는 확인 필요. 몬스터·도구별 피해는 각 콘텐츠 문서, 매몰 주기 피해는 갱도 문서가 관리한다.

- **E 줍기 판정 순서**: 조준 대상 선택 → 현재 상태에서 그 대상을 주울 수 있는지 → 그 대상이 쓰는 슬롯에 공간이 있는지. 일반 물품은 일반 슬롯, 시체는 시체 전용 슬롯을 본다. 일반 슬롯이 가득 차도 시체 슬롯이 비어 있으면 시체를 주울 수 있다. 상태 제한·슬롯 부족으로 실패하면 그 입력은 줍기 실패로 끝나고 **다른 대상으로 넘기지 않는다**.
- 중량 감속 공식·kg 환산은 미정이다(장비 중량은 기획, 회수품 중량은 경제 담당). 운반 때문에 달리기 외의 추가 스태미나 소모를 붙이지 않는다.

## 매몰과 상태별 행동

| 매몰 | 이동 | 시야·시점 | 해제 |
|---|---|---|---|
| 1단계 | 100cm/s 시험값 | 시야 가림 없음 | 영역 밖으로 이동 |
| 2단계 | 50cm/s 시험값 | 흙이 튄 정도의 시야 가림 | 영역 밖으로 이동 |
| 3단계 | 이동 불가 | 시점 회전 가능, 시야는 아주 조금만 보임 | 동료가 덮인 흙을 치워 신체가 완전히 드러나면 구조 |

- 모든 매몰 단계에서 달리기·점프 불가. 자력 탈출 키·게이지 없음. 스태미나가 회복돼도 매몰 제한은 유지한다. 회수품은 유지하고 직접 내려놓을 수 있다.
- 3단계는 엎드린 채 흙에 깔리고, 신체 일부가 잔해 밖으로 드러나 동료가 발견할 수 있어야 한다. 매몰 위치 표시는 없다. 노출 부위는 연출 세부로 미정이다.
- 붕괴용 흙은 굴착용 흙과 다른 텍스처를 쓰고 1·2·3단계마다 다른 모양으로 만든다. 플레이어가 없는 잔해도 단계별로 구분된다. 연출은 흙먼지와 함께 상부에서 토사를 생성해 연속 낙하시키는 방식이다.
- 더 높은 단계의 추가 붕괴는 단계를 갱신하고, 3단계로 갱신되면 매몰 흙을 새로 만든다. 같거나 낮은 단계는 기존 상태와 **파낸 양**을 유지한다. 시간만으로 단계가 오르지 않는다.
- 실제 출발 인원 1명인 탐사에서 3단계 매몰은 즉사. 도중 사망·접속 종료로 출발 인원을 다시 계산하지 않는다. 다인 탐사에서 남은 생존자가 모두 3단계여도 즉시 전멸시키지 않고 매몰 피해 사망까지 기다린다.

### 3단계 파서 구조하기 (확정)

| 항목 | 규칙 |
|---|---|
| 구조 방식 | 엎드린 매몰자 쪽으로 좌클릭으로 파고 들어가 위의 흙더미를 치운다. 신체가 완전히 드러나면 구조 완료. 누적 굴착량·주변 흙 전체 제거·설 공간 확보는 완료 조건이 아니다. **E 유지 구조는 폐지** |
| 대상 | 3단계만. 1·2단계는 느린 이동으로 영역을 벗어나 해제 |
| 매몰 흙 | 3단계 매몰 때 생기는 별도 굴착 대상(통로 잔해와 구분). 완전 노출 시 매몰 해제·주기 피해 종료. 구조·사망 뒤 남은 매몰 흙과 통로 잔해는 유지하고, 이동 공간은 별도로 굴착. 자동 제거 없음 |
| 맨손 | 가능. 한 번에 파내는 양이 도구보다 적음(비율은 시험값) |
| 동시 구조 | 여러 명이 동시에 팔 수 있고 실제로 파낸 결과를 함께 반영. 인원 제한 없음 |
| 진행 유지 | 중단·자리 이탈·구조자 사망·연결 종료에도 파낸 양 유지. 3단계 중 추가 붕괴에도 유지 |
| 타격 판정 | 매몰 흙에 맞으면 굴착, 드러난 신체에 맞으면 일반 공격 피해(탐사 중 팀킬 기준) |

- 매몰자가 사망해도 남은 흙은 유지한다. 시체 일부가 드러나 집기 기준을 충족하면 회수할 수 있다(완전 노출 불필요, 집기 노출 기준은 시험으로 정함). 미스터리 박스의 시체 소멸 예외는 유지한다.
- 완전 노출 판정의 검사 신체 범위·대상 흙·허용 오차(등·발끝의 작은 흙 조각, 바닥 접촉부 포함 여부)는 개발팀과 정한다. 보기에 구조된 상태와 실제 완료 판정이 일치해야 한다. 기획서도 수치를 확정하지 않았다.

## 사망·관전·복귀·음성

- 일반 사망은 일반·히든 슬롯·헤드랜턴을 포함한 소지품을 현장에 떨어뜨린다. 개인 재화는 돈주머니로 떨어뜨리지 않는다. 미스터리 박스 포식은 시체·소지품 전부 소멸이며 일반 드롭보다 우선한다.
- 탐사 중 사망 직후 관전. 탐사 종료 후 정산 대상을 확정한 뒤 로비에서 부활하고 기본 삽·헤드랜턴을 지급한다.
- **일반 로비 사망**: 잔고 50% 손실(잠정, 손실액 올림, 런 플로우 v1.1.0 4.1절), 사망 5초 뒤 엘리베이터 앞에서 부활, 소지품은 죽은 자리에 떨어지고 누구나 주울 수 있다(돈은 떨어지지 않음). 부활 대기 중 출발 인원으로 소집되면 출발 인원에 포함하고 5초가 끝날 때 엘리베이터 안에서 부활한다. 떨어뜨린 장비는 로비에 남고 본인만 출발한다.
- **최초 하강 예외**: 로딩을 마치고 갱도에 들어가기 직전에도 사망 상태면 남은 대기와 관계없이 엘리베이터 안에서 즉시 부활한다. 로비에 떨어진 장비를 옮기거나 다시 지급하지 않고, 이미 적용한 로비 사망 손실을 탐사 정산에서 중복 차감하지 않는다. 갱도 진입 후 탐사 사망에는 적용하지 않는다.
- **게임 오버 실패 사건**: 일반 로비 사망·잔고 손실·5초 부활을 중단하고 흡입·대기를 우선한다. 침수·흡입 중 익사·낙사로 추가 사망·손실·반복 부활을 만들지 않는다.
- 관전: 살아 있는 탐사자를 좌클릭 이전 / 우클릭 다음으로 바꿔 본다.
- 로비에서 퇴장·끊김은 캐릭터 제거·자리 반환, 장비는 현장에 남김. 탐사 출발 후 퇴장·끊김은 캐릭터·자리 유지, 같은 캐릭터 최신 상태로 복귀하며 그동안의 결과를 적용(기존 기준과 같음).
- 음성: 같은 구역 생존자 근거리(3m 원래 음량·최대 25m 시험값, 벽·층 추가 감쇠 없음), 갱도↔던전 양방향 차단, 매몰자는 먹먹하게·최대 거리 절반 시험, 관전자끼리 대화하고 생존자를 들음(생존자는 관전자를 못 들음), 정산 중 구분 유지 후 로비 조작 복구 때 해제. 기존 기준과 같다.
- 아트·UI: 로우폴리, 캐릭터 텍스처 상한 1024, 1인칭 팔과 전신 모델·팔/몸/머리 모듈. UI는 체력·스태미나·고갈·재달리기 가능 상태·매몰 시야를 읽을 수 있게 검토한다.

## 현재 구현과의 차이 (2026-11-14 코드 대조, 실행 확인 전)

코드는 바꾸지 않았다. 아래는 구현 작업에서 맞춰야 할 차이다.

- `Content/Data/Player/DT_PlayerStats.csv`(2026-11-13 커밋 fc59664): 달리기 소모 20, 점프 비용 10, 회복 12, 회복 대기 1초, 재개 기준 20, 음수 게이지 없음. 기획서는 10 / 0 / 5 / 2초 / 0 초과 / -20이다. 고갈 후 새 Shift 필수, 공중 달리기 소모, 사망·관전 중 정지·게이지 숨김, 초기화 시점도 확인이 필요하다.
- 같은 표의 `ScaleX/Y/Z`는 1/1/1이다. 기획서는 1.2/1.2/0.85다. 2026-11-12 사용자 결정(D26)의 메시 균등 확대와 이 스케일의 관계는 캐릭터 구현 담당이 확인한다.
- 매몰 구조는 프로토타입 코드(`Prototype/` GameMode·PlayerController)의 E 유지 단독 점유 방식이다. 기획서의 매몰 흙 굴착 구조와 다르다.
- 낙하 피해·로비 사망 부활은 제품 코드(`Game/`)에 없다.

## 구현 후 확인할 시나리오

기획서의 T01~T15는 작업리스트 인수 시나리오 T01~T93과 번호가 겹치는 **별도 목록**이다. 여기서는 `CHT01~CHT15`로 부른다. 요구사항이며 실행 기록이 아니다.

- CHT01: 100에서 12초 달리기, 0 이후 음수로 계속, -20에서 고갈, UI는 0에서 멈춤
- CHT02: 고갈 후 Shift를 계속 눌러도 자동 재개 없음
- CHT03: 고갈 후 2초 회복 시작, 6초 0, 양수가 되면 재달리기 가능, 26초 100 / CHT03-1: -5에서 멈추면 양수 전까지 달리지 않음
- CHT04: 시작 실패·비소모 행동이 회복 대기를 초기화하지 않음
- CHT05: 웅크림 기립 공간, 공중 추가 점프 차단
- CHT06: 매몰 단계별 이동·시점, 스태미나와 상태 제한 분리
- CHT07: 양손 운반 중 달리기·점프, E 줍기 판정 순서, 추가 줍기 차단, 일반 슬롯이 꽉 차도 빈 시체 슬롯으로 시체 획득, 슬롯 부족 시 다른 대상으로 넘기지 않음

- CHT10: 같은 중량·상태에서 모든 방향 달리기 속도 동일, 대각선 합산 가속 없음
