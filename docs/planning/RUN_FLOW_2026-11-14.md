런 플로우 v1.0.1(2026-11-10)은 6.1·6.6·9.4절만 문서에 반영했다([몬스터 반영 기준](MONSTER_DESIGN_2026-11-08.md)). 이 문서는 v1.0.1 → v1.1.0의 바뀐 점과 그에 따른 저장소 문서 갱신 범위를 정리한다. 기획서 스스로 문서 전체를 승인 전 초안으로 두고, 항목마다 확정·시험·잠정·예정·미정을 구분한다. 이 구분을 그대로 옮긴다. 반영했다고 해서 Notion 승인, 구현, 플레이 수용이 끝났다는 뜻은 아니다.

[캐릭터 기획서 v1.0.0](CHARACTER_DESIGN_2026-11-14.md)이 근거로 삼은 런 플로우 v1.1.0이 이 문서다(PQ-46 해결). 캐릭터 기획서와 겹치는 매몰 구조·조작 키·로비 부활은 두 문서가 같은 내용이다.

## 사용자 결정과의 충돌

- **시작 잔고**: [사용자 결정 4](DECISIONS.md#사용자-결정-2026-11-05)(2026-11-05)는 "출시 빌드 새 게임은 개인 잔고 0원"이다. 당시 작업리스트의 0원과 같은 값이었다. v1.1.0은 1인당 20(잠정)이다. **2026-11-14 사용자가 기획대로 20으로 바꾸라고 결정했다.** 사용자 결정 4의 시작 잔고 부분을 대체하고 코드 상수 `StartingBalanceCredits`를 20으로 바꿨다. 개발 빌드 시험 지원금 500은 별개로 유지한다.

## 남은 결정 (기획서 13절)

- 긴급 삽: 미접속 참가자의 보관 잔고 포함 여부, 로비 맵 밖·접근 불가 위치 도구의 산정 범위.
- 로비 사망: 회수 가능한 로비 시체의 생성 여부·제거 시점, 로비 사망 손실의 게임 오버 통계 포함 여부.
- 1~3일차 목표 달성 납부와 레버 완료가 같은 처리 시점일 때의 우선순위.
- 몬스터: 레벨별 던전 파워 한도·기간별 증가 방식, 파워 예정값 승인, 스폰 곡선 값, 두더지·지렁이 생성 위치·예고·최소 거리·종별 최대 수·매몰 처리, 갱도 골렘 스폰 유형, 허수아비 분신의 파워 점유 여부, 땅거미 시체 고치의 S22 의존.
- 매몰: 굴착 1회당 제거량·맨손 비율·신체 완전 노출 판정 범위·시체 집기 노출 기준·전원 매몰 후 사망 대기 시간.

## 현재 구현과의 차이 (2026-11-14 문서 기준, 코드 실행 확인 전)

코드는 바꾸지 않았다. 구현 현황 문서와 결정 목록의 '현재 구현' 서술로 본 차이다.

- 정산: 사망 손실 100%·시체 회수 시 사망 직전 잔고 50% 복구(내림)·전멸 시 유효 시체 복구금 지급이 구현돼 있다(자동 테스트 통과). v1.1.0은 복구금 없이 손실률 자체를 50%로 줄이고 올림한다. 결과 크레딧의 사망 손실 순액 계산도 바뀐다.
- 보강·목재: 프로토타입과 굴착 구현에 보강·수리가 있다. v1.1.0에서 문서 범위 밖(Could)이 됐으므로 새로 넓히지 않는다. 기존 코드를 지울지는 결정하지 않았다.
