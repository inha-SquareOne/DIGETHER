### 일반 물품과 인벤토리 연결 방향

2026-11-06 사용자는 **담당 인벤토리 계약에 연결해 기존 세이브를 확장**하는 방식을 선택했다. 독립 월드 물품 체계를 따로 만들지 않는다. 현재 로컬 `Game/`에는 일반 장비의 월드 인스턴스·인벤토리 연결 계약이 없고, 바닥 물품 저장은 금화 더미 전용이다. 따라서 아래는 구현 완료가 아닌 담당 간 연결 조건이다.

- 인벤토리/월드 물품 계약에서 안정적인 인스턴스 식별자, 아이템 정의 ID, 수량, 월드 Transform, 소지/바닥/운반/설치 상태와 구역·탑승 편을 제공해야 한다. 상태를 누가 소유하는지는 담당 구현의 계약을 먼저 확인한다.
- 공식 저장 시점에 호스트가 일반 바닥 물품 스냅샷을 기존 저장에 포함한다. 기존 파일·백업과 일관되게 읽고 쓰며 과거 저장에 물품 확장 정보가 없을 때의 호환 읽기와 중복 지급 방지를 검증한다. 현재 금화 구조를 일반 장비로 억지 변환하지 않는다.
- 거점 로드 시 종류·수량·위치·방향을 복원한다. 끼임·맵 밖 판정과 엘리베이터 안전 위치는 실제 충돌·맵 계약으로 정하고, 유효한 바닥 배치까지 이동시키지 않는다.
- 전멸·탐사 종료의 장비 보존/소멸, 설치 지지면 소실 후 낙하·재사용, 갱도·던전 유실 제거를 같은 물품 상태로 처리한다. 시체 운반 중 구조 거절과 새 게임 시작 장비 1회 지급도 인벤토리/운반 상태를 연결한다.
- 인벤토리 담당 구현/API를 확인하기 전에는 임의 클래스·세이브 버전·끼임 판정 수치를 확정하지 않는다. 확인 후 기존 `Game/Save`·`DigetherGameplaySave`와 연결하고 구버전 로드·손상·반복 로드·전멸·다인 경합을 검증한다.
