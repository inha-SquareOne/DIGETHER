# DIGETHER 결정과 미결 사항

기준일: 2026-10-28 · **Notion 이관 전 초안**. 사용자 확정인 엔진 버전과 문서 운영은 각각 [ADR-003](../decisions/ADR-003-engine-version-5.8.4.md), [ADR-001](../decisions/ADR-001-document-ownership.md)을 따른다. 아래 D15~D40은 제공된 개발팀 작업리스트의 식별자이며 이전 문서의 D-003~D-013과 다른 체계다. 자료 내 확정·잠정·미정을 실제 Notion 승인으로 격상하지 않는다. 담당자와 기한은 별도 확인한다.

## 사용자 추가 결정과 시험값

2026-10-28 사용자는 굴착을 Digging a Hole처럼 조준한 흙이 실제로 깎여 구멍을 넓히고 아래로 팔 수 있는 방식으로 명시했다. 이 방향은 더 이상 미결이 아니다. 갱도의 허용 3D 흙 볼륨과 던전 지정 파괴 벽은 구분하며, T02~T03의 방향별 허용 영역·동시 제거량·비허용 구조물 보존을 유지한다. [굴착 구현 설계](../design/EXCAVATION_IMPLEMENTATION.md)의 최초 8m × 8m × 격자 깊이 약 2.5m(굴착 가능 깊이 약 2.15m) 및 벽 방향 회전 시험은 기술·플레이 fixture이고 최종 지형 크기·깊이·성능 예산 확정은 아니다.

사용자 추가 이미지의 어두운 Low Poly 광산·따뜻한 작업등·목재 지지대·철제 승강기·1인칭 도구·폐교 분위기는 프로토타입 표현에 반영한다. 이미지의 수분 아이콘 등에서 새 생존 규칙을 추정하지 않는다. 신규 프로토타입/새 게임 기본 삽 1개·2kg는 이번 플레이 시험용 지급값이다. 정식 지급품·수량·중량인 D22와 기본 목재 위치·수량인 PQ-04를 닫지 않는다. D17/D18/D19/D23/D30 등 나머지 미결도 별도로 유지한다.

**사용자 결정 2026-10-29**: 출시 방향은 Steam 판매다. 정식 App ID, 세션 서브시스템(OnlineSubsystemSteam 또는 EOS), 음성 제공자, Steam Cloud 사용 여부, 다른 플랫폼 동시 출시는 미결이다. 프로토타입의 App ID 480 시험은 정식 값이 아니다.

세션/음성 제공자, 저장 형식과 기술적 복제 방식, 성능 예산, 코드·에셋 담당 및 Notion 승인자는 여전히 확인이 필요하다. 기존 D-004의 호스트형 여부, D-006의 1인 3단계 매몰·관전, D-007/008의 여러 경제·귀환 규칙 등은 새 자료가 구체화하므로 이전 미정 서술을 그대로 적용하지 않는다. 반대로 새 자료가 답하지 않은 나머지 하위 질문을 자동으로 닫지 않는다.

결정 기록에는 실제 결정자·일자·승인 근거, 요구 ID·개정, 이유, 영향, 대체 관계를 남긴다. 기획 결정은 Notion, 기술 선택은 검증 후 GitHub ADR에 기록하고 서로 연결한다.
