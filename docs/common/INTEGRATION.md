# 프로젝트 스킬·역할 관리

## 스킬

관리 원본이자 Codex 발견 경로는 `.agents/skills/`다. Claude Code용 `.claude/skills/`는 같은 작업에서 지원 파일과 상대 링크까지 동일하게 갱신한다. 전체 목록과 실행 조건은 [프로젝트 스킬](../tools/SKILLS.md)을 따른다.

## 역할

역할 원본은 `docs/ai/roles/`와 `agents/catalog.json`이다. 변경 시 `.claude/agents/` 및 `.codex/agents/`의 해당 설명·도구·지침을 맞춘다. 역할 본문 링크는 프로젝트 루트 기준, 스킬 링크는 파일 위치 기준이다. 역할 설치는 실행·위임 허가를 뜻하지 않는다.

Codex 0.160.1 `codex exec`에서 사용자 지정 역할을 하위 에이전트로 띄울 때는 `--ephemeral`을 쓰지 않는다. 부모 세션 기록이 없어 하위 에이전트 생성이 실패한다(2026-10-27 확인). 하위 에이전트를 쓰지 않는 읽기 전용 교차 검증에는 영향이 없다.

## 검증

[AGENTS.md](../../AGENTS.md)가 프로젝트 진입 지침이다. 변경 후 로컬 링크·구조화 파일 문법·두 스킬 경로 일치를 확인한다. 실제 도구 발견·연결·호출은 별도로 검증하고 확인하지 못한 결과는 미검증으로 보고한다.

## 지침이 실제로 읽혔는지 확인

진입 내용의 원본은 루트 `AGENTS.md`다. Claude Code의 직접 로드는 버전·상위 디렉터리 파일·설정에 따라 달라지므로 파일 존재만으로 단정하지 않는다. 지원 버전과 기본 설정에서는 현재/상위 경로에 `CLAUDE.md`, `.claude/CLAUDE.md`, `CLAUDE.local.md`가 없을 때 읽는다. 새 세션의 `/memory` 또는 `/context`에서 실제 로드를 확인한다.

직접 로드가 안 되는 환경에서는 `CLAUDE.md`에 본문을 복제하지 말고 `@AGENTS.md` import로 연결하는 방법을 사용한다. 기존 파일·설정을 확인한 뒤 필요한 범위만 변경한다. 이 문서 정리에서는 전역 설정이나 진입 파일을 자동 생성하지 않았다.

근거: [Claude Code 공식 지침 로드 안내](https://code.claude.com/docs/en/memory), 2026-10-23 확인. 개인 PC마다 실제 로드 여부는 별도로 검증한다.
