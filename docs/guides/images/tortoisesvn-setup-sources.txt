프로젝트 기준
- docs/decisions/ADR-004-git-code-svn-assets.md

- Git 코드·설정·문서 + SVN Content·제작 원본 방향 채택, 실제 도입은 보류.
- 팀 PC 서버 개설은 사용자 보고. 실제 저장소 URL·계정·접속은 이번 작업에서 확인하지 않음.
- 현재 Git LFS 운영 유지. 안내 이미지 제작은 서버 구성·에셋 이관 실행이 아님.
- 실제 저장소 URL·작업 폴더·잠금 대상은 미등록 또는 미결이므로 자리표시자와 조건부 안내를 사용함.

검증 범위
- 공식 문서와 프로젝트 상태 대조, 최종 이미지 시각 확인.
- 설치·서버 접속·Checkout·잠금·Commit 실기는 수행하지 않음.
- 관리자 계정/권한·백업·잠금 자동 적용·Git/SVN 리비전 짝 규칙은 이관 전 별도 결정 사항.
